# 도카도카 영어 공부 · 73 Questions With Zendaya

YouTube 영상 「73 Questions With Zendaya | Vogue」(Vogue 공식, 2019-05-31, 12분 12초, 조회 2,700만)의
**Vogue 공식 영어 캡션(화자 표시 포함)** 으로 만든 **영어 학습 카드 앱**(한국어 모어 학습자용).
대사 248장, 한국어 뜻·주석 병기(주석 206장).

인터뷰어가 젠데이아의 집(정원·화덕·나무 아래)을 돌며 73가지 질문을 던지고 짧게 답을 받는 형식입니다.
질문은 `What would you say is…?` `How would you describe…?` 같은 정중한 문형이 반복되고,
답은 `Yeah, for sure.` `Probably my Converse.` 처럼 짧고 캐주얼합니다.
발음이 또렷하고 속도가 보통이라 **중급 듣기·회화 교재**로 적당합니다.
`japanese-cards/`(Snow Man 인터뷰)와 같은 구조이며, 이 폴더만 통째로 복사하면 다른 PC에서 그대로 실행·재빌드됩니다.

---

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8096). Python 3 가 필요합니다.

`English-Zendaya248-Cards.html` 을 그냥 더블클릭해도 카드·대본·학습·편집은 쓸 수 있지만,
**YouTube 가 `file://` 에서의 임베드 재생을 거부**하므로(Error 153) 재생 버튼은 YouTube 를 해당 대사 시각부터 새 탭으로 엽니다.
어느 방식이든 **인터넷 연결**이 필요합니다.

---

## 기능

- **카드** — 영어 대사 + 한국어 뜻(가리기/보기) + 주석, 장면·화자별 필터, 체크 진도
- **화자** — 캡션의 `[Interviewer]` `[Zendaya]` `[Darnell]` 표기를 살려 인터뷰어 111장 · 젠데이아 135장 · 다넬 2장으로 볼 수 있음
- **장면** — YouTube 공식 챕터(질문 28개)를 화제별 11장면으로 묶음(인사 → 성장 → 캘리포니아 → 유포리아 → SNS → 패션 → 뷰티 → 셰익스피어 → 스턴트 → 음악 → 마무리)
- **대본** — 248줄 목록(시각·화자·대사·뜻), 줄 클릭 시 그 위치부터 재생, 재생 중 자동 추종
- **재생** — 대사 시작점으로 점프, 구간 반복, 다음 카드 자동 재생, 재생 여유(기본 0.5초)
- **오늘** — 248장을 페이스(천천히 18 / 보통 25 / 빠르게 36 / 집중 50장)로 나눈 일일 분량. 보통 기준 10일 완성
- **학습** — 표현 49 · 단어 67. 각 항목이 나오는 자막 위치를 자동으로 찾아 예문·클립 재생 연결(클립 135개)
- **퀴즈** — 표현/단어/대사/오늘 분량 × EN→KO / KO→EN / 듣기, 4지선다
- **학습법** — 4단계 가이드와 팁 6가지(축약·필러, 질문 말투와 대답 말투 등 이 영상에 맞춰 씀)
- **직접 편집** — 대사·뜻을 고쳐 저장(브라우저 저장). `내보내기`/`가져오기` 로 백업·이전

> 학습 기록(체크·직접 수정한 내용)은 파일이 아니라 **브라우저**에 저장됩니다.

일본어 앱과 다른 점: 영어에는 읽기(후리가나) 줄이 없으므로 읽기 토글·`R` 키·읽기 편집란을 뺐고, 이 영상에는 화면 자막이 없어 「화면 자막 포함」옵션도 없습니다.

## 구성

```
english-cards/
├─ English-Zendaya248-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh            실행기
├─ README.md
└─ src/
   ├─ subtitles.srt                원본 자막 (YouTube · Vogue 공식 영어 캡션 en-US, yt-dlp 로 받음)
   ├─ chapters.json                YouTube 공식 챕터 28개 (장면 구분 근거)
   ├─ seg.py                       자막 → 카드 분할 (화자 태그·교대 추정·긴 답변 문장 분할)
   ├─ build.py                     최종 HTML 생성 (seg.py 를 먼저 실행)
   ├─ tpl.html                     화면 템플릿 (HTML/CSS/JS)
   ├─ ko.txt                       한국어 번역·주석 248건   `id|뜻|주석`
   └─ study.txt                    학습 표현·단어 116건     `종류|영어|뜻|메모`
```

## 재빌드

```bash
python3 src/build.py
```

번역 id 와 카드 id 가 전수 대응하는지, 학습 항목이 모두 자막에서 발견되는지(`0개: 없음`)를 빌드가 검사합니다.

### 이 자막 형식의 특징 (seg.py)

Vogue 의 공식 캡션은 미국 방송용 캡션 규칙을 따릅니다.

- `- [Interviewer] 대사` — 화자 태그가 붙은 새 발화. 태그는 화자가 화면에 없거나 불분명할 때만 붙습니다.
- `- 대사` — 태그 없는 새 발화. 2인 인터뷰이므로 **직전 화자의 상대**가 말한 것으로 추정합니다(147장). 추정이 틀리는 곳(제3자 다넬 등장, 대시 없이 사람이 바뀌는 줄)은 `seg.py` 의 `LINE_FIX` 에 줄 원문으로 지정해 두었습니다(6곳).
- `[dog barks]` 같은 효과음 줄은 카드에서 제외합니다. 태그 오기 `[Darrel]` 은 `Darnell` 로 통일했습니다.
- 답변 한 개가 300자를 넘기도 하므로 120자를 넘으면 **문장 끝에서 나누고**, 시각은 줄 단위 큐 시각에서 보간합니다(39장).
- `heals`(→heels) 처럼 캡션 자체의 오타는 원문 그대로 두고 주석에 적었습니다.

### 다른 영상으로 바꾸려면

1. `yt-dlp --list-subs` 로 **`en-US`(수동 캡션)** 가 있는 영상을 고르고 `--sub-langs en-US --convert-subs srt` 로 받아 `src/subtitles.srt` 에 둡니다.
2. `python3 src/seg.py` 로 분할 결과를 확인하고 화자 추정을 `LINE_FIX` 로 고칩니다.
3. `src/ko.txt` 와 `src/study.txt` 를 새로 쓰고, `build.py` 의 `VID`·`SCENES`·`SPEAKERS`·출력 파일명을 바꿉니다.
4. `start.sh`/`start.bat` 의 파일명·포트, `tpl.html` 의 `LS` 키와 내보내기 파일명을 바꿉니다(안 바꾸면 두 앱의 진도가 섞입니다).

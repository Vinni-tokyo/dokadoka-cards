# 도카도카 일본어 공부 · 僕の心のヤバイやつ 제1화

YouTube 영상 「【期間限定】TVアニメ「僕の心のヤバイやつ」第1話｜特別公開！」(tv asahi animation 공식, 2023-04-09, 23분)의
**자동생성 자막**을 교정해 만든 **일본어 학습 카드 앱**(한국어 모어 학습자용).
대사 76장 + 속마음 108장 = 184장, 히라가나 읽기·한국어 뜻·한자 풀이 병기.

중학생 이치카와가 학교 제일의 미인 야마다를 「죽이는 망상」을 하며 관찰하다가 조금씩 엮이는 1화입니다.
속마음 독백이 많고 문장이 짧아, 반말·속어를 포함한 **중학생 일상 일본어**를 배우기 좋습니다.
`yubisaki-cards/` 와 같은 구조이며, 이 폴더만 통째로 복사하면 다른 PC에서 그대로 실행·재빌드됩니다.

> ⚠️ 영상 제목에 「期間限定」(기간 한정)이 붙어 있습니다. 2023년 4월 공개 이후 계속 유지되고 있지만 언젠가 내려갈 수 있습니다.

---

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8093). Python 3 가 필요합니다.
상위 폴더의 `start.bat`/`start.sh`(포트 8100)로 열면 관문 페이지에서 다른 영상 앱과 함께 고를 수 있습니다.
YouTube 는 `file://` 에서의 임베드 재생을 거부하므로(Error 153) 서버로 여는 것이 기본이며, 인터넷 연결이 필요합니다.

## 기능

- **드릴** — 학습 탭의 기본 화면. 유튜브 없이 단어·표현만 외우는 암기 드릴. 브라우저 내장 음성(TTS)으로 읽어 주고, 카드를 보고 떠올린 뒤 「몰라/애매/알아」로 채점하면 틀린 것은 같은 세션에서 곧 다시 나오고, 세션이 끝나면 0·1·3·7·14일 간격으로 다시 물어봄(브라우저에 저장). 방식은 日→韓 / 韓→日 / 듣기, 「자동 반복 듣기」는 손을 놓고 원문→뜻→원문 순으로 계속 읽어 줌. 「영상」 버튼으로만 원음을 들음
- **카드** — 일본어 대사 + 히라가나 읽기(토글) + 한국어 뜻, 장면·화자별 필터, 체크 진도
- **원문 병기** — 자동자막 오인식을 고친 106장은 읽기 아래에 「원문」을 함께 표시
- **한자 풀이** — 뜻 영역에 한자어마다 일본어 독음 · 한국 한자음 · 뜻 · 낱글자 훈음 (`src/words.txt` 248어 · `src/kanji.txt` 279자)
- **표현 풀이** — 그 카드에 나오는 학습 표현(문형)의 뜻과 메모
- **재생 구간 보정** — 「옆 카드 침범 금지」(기본 켜짐)로 붙어 있는 카드 사이에 앞뒤 대사가 새어 들어오지 않게 하고, 「시작 보정」(−0.3~+0.5초)과 카드별 「재생 구간 조정」(편집 박스: 시작/끝 ±0.3초, 「지금 위치로」)으로 자막 시각의 어긋남을 바로잡을 수 있음. 조정값은 브라우저에 저장되고 내보내기/가져오기에 포함
- **속마음** — 이치카와의 심중 독백 108장을 별도 칩으로 표시. 옵션으로 카드에서 뺄 수 있음
- **화자** — 자막에 화자가 없어 번역과 함께 손으로 지정(이치카와·야마다·코바야시·모에·칸자키·난조·아다치·선생님·점원·남녀 학생)
- **대본 · 재생 · 오늘 · 학습(표현 56 · 단어 46) · 퀴즈 · 학습법 · 편집/내보내기** — 다른 앱과 동일

## 구성

```
bokuyaba-cards/
├─ Japanese-BokuYaba184-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh               실행기
├─ README.md
└─ src/
   ├─ subtitles.srt                   원본 자막 (YouTube 자동생성, yt-dlp 로 받음)
   ├─ seg.py                          자막 → 카드 분할 (겹치는 시간 보정·ED 가사 제외)
   ├─ fixes.txt                       인식 오류 교정 106건  `id|교정문`
   ├─ build.py                        최종 HTML 생성 (seg.py 를 먼저 실행)
   ├─ tpl.html                        화면 템플릿 (HTML/CSS/JS)
   ├─ ko.txt                          번역·읽기·주석·화자 184건  `id|뜻|읽기|주석|화자`
   ├─ words.txt                       한자어 사전 248건        `어간|표제|독음|뜻|한자음`
   ├─ kanji.txt                       한자 훈음 사전 279자     `漢字|훈 음`
   └─ study.txt                       학습 표현·단어 102건     `종류|일본어|읽기|뜻|메모`
```

## 재빌드

```bash
python3 src/build.py
```

### 이 자막 형식의 특징 (seg.py)

- 자동생성 자막은 **큐당 한 줄이고 종료 시각이 다음 줄과 겹칩니다**. 각 줄의 실제 발화 구간을 「이 줄 시작 → 다음 줄 시작」으로 잘라 씁니다.
- 화자·속마음 표기가 없으므로 `ko.txt` 5번째 칸에 손으로 지정합니다(`市川〈〉`=속마음, `A·B`=한 카드에 둘 이상).
- 줄이 문장 중간에서 끊겨 있어, 간격 1초 이내·30자 이내로 잇되 문장 끝 어미(よ·ね·か·だ 등)에서는 끊습니다.
- 21:30 이후 ED 가사는 인식이 되지 않아 제외했습니다.
- 오인식은 `fixes.txt` 로 고칩니다(近郊→均衡, コトコット→カッター, 正当性→政党制, 鉢→波長 등). 원문은 앱에 병기됩니다.

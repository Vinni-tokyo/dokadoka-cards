# 도카도카 일본어 공부 · ドカドカ日本語 — 4.5Music「輝く日を仰ぐとき」

YouTube 「How Great Thou Art (Japanese Worship) 輝く日を仰ぐとき」(4.5Music, 5분 54초)로 만든
**일본어 찬양 학습 카드 앱**(한국어 학습자용). 32줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 15·단어 12.
한국 찬송가로는 「주 하나님 지으신 모든 세계」.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- **공식 채널에 일본어·한국어 자막이 둘 다 붙어 있고 32줄이 그대로 맞물립니다.** 음성 인식을 쓰지 않았습니다.
- **문어(文語) 찬송가**입니다. 「〜とき」가 세 줄 잇따르고(仰ぐとき·眺るとき·鳴り渡るとき),
  후렴 「わがたま いざたたえよ 大いなる御神を」가 여덟 번 돌아 문어 명령형이 몸에 붙습니다.
- 雷(いかずち)·音(ね)·世人(よびと)·眺る(ながむる)처럼 **일상과 다른 문어 읽기**가 나옵니다.
- 3절(독생자)·4절(다시 오실 주)에서 〜せたり·来たり·〜たまわん·〜ぞ 같은 문어 어미를 봅니다.

## 줄 시각·한국어 뜻

공식 자막 두 벌에서 만들었습니다. 시각은 손대지 않았습니다.
한국어 자막은 한국 찬송가 가사(의역)라, **뜻은 일본어를 그대로 옮기고** 찬송가 가사는 주석에 적었습니다.
박 그리드는 `beats.py` 로 구했습니다(BPM 116.0).

## 읽어주기가 잘못 읽던 한자

| 본문 | 합성기가 읽던 소리 | 이 곡의 읽기 |
|---|---|---|
| 雷 | かみなり | **いかずち** |
| 鳥の音 | とりの**おと** | とりの**ね** |
| 世人 | **せじん** | **よびと** |
| 眺るとき | **ちょう**る | **ながむ**る |
| 主 | (자리에 따라 ぬし) | しゅ |

`tools/check_reading.py` 로 짚고 `tools/hear_tts.py` 로 실제 소리를 재어 가린 것만 `src/tts_fix.txt` 에 적었습니다.
같이 짚힌 御神·栄え(さかえ)는 제대로 읽고 있어 건드리지 않았습니다.

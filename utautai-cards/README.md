# 도카도카 일본어 공부 · ドカドカ日本語 — 斉藤和義「歌うたいのバラッド」

YouTube 「斉藤和義 – 歌うたいのバラッド（2008 Ver.）[Music Video]」(斉藤和義 공식 채널, 6분 52초)로 만든
**일본어 노래 학습 카드 앱**(한국어 학습자용). 32줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 20·단어 12.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- **공식 채널 설명란에 가사가 올라 있습니다**(작사·작곡 斉藤和義 본인). 가사는 그것을 그대로 썼습니다.
- 「노래하는 건 어려운 일이 아니야」로 열어 「사랑해」 한마디로 닫습니다. 같은 자리의 말이 바뀝니다 —
  12번 「言えなかった言葉」→ 30번 「素敵な言葉」, 13번 「短いから」→ 31번 「短いけど」.
- 〜ておくれ·〜ばいい·〜だって·〜ながら·가능형 부정(言えない·言えなかった)이 고루 나오고,
  「노래하다」에 唄う, 「노래」에 歌 를 갈라 씁니다.

## 줄 시각

자막 트랙이 없어 **음성 인식(faster-whisper medium, 단어 시각)** 으로 맞췄습니다.
`tools/asr_words.py` 로 단어 시각을 뽑고 `tools/align_dp.py` 로 가사 32줄을 순서 정렬했습니다
(**32줄 전부 직접 대응**, 유사도 평균 0.93). 받아쓰기로 확인한 부른 차례가 설명란 가사와 같아
반복을 더하지 않았습니다. 박 그리드(`src/beats.json`)는 `beats.py` 로 구했습니다(BPM 150.2).

## 읽어주기

`tools/check_reading.py` 가 何 한 곳을 짚었고, 嗚呼·唄う·空 과 함께 `tools/hear_tts.py` 로 재어 보니
모두 제대로 읽고 있어(なに·ああ·うたう·そら) 보정하지 않았습니다.

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8125). 학습 탭·노래방·화면 잠금은 다른 노래 앱과 같습니다.

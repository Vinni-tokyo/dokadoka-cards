# 도카도카 일본어 공부 · ドカドカ日本語 — 성시경의 만날텐데 · 나카시마 미카

YouTube 「[sub] 성시경의 만날텐데 l 나카시마 미카」(성시경 SUNG SI KYUNG 공식 채널, 2026-04, 25분 52초)로 만든
**일본어 학습 카드 앱**(한국어 학습자용). 640장(대사 587 + 화면 자막 53).

성시경이 일본어로 진행하고 나카시마 미카가 일본어로 답하는 **전편 일본어 대화**입니다.
닭곰탕을 먹으며 한국 공연, 흰쌀밥 사랑, 고향 가고시마, 18살 상경과 데뷔, 무대 긴장과 인이어,
한국 노래 커버까지 이야기가 이어집니다.

## 왜 이 영상이 좋은 재료인가

- **공식 수동 일본어 자막**(자동생성 아님). 615개 큐, 구두점·화자 대시가 붙어 있고 큐 겹침이 0입니다.
  지금까지 만든 일본어 앱 중 자막 품질이 가장 좋습니다.
- **두 가지 일본어를 비교**할 수 있습니다. 성시경의 또박또박한 학습자형 일본어(〜んですが·〜ですよね)와
  나카시마 미카의 자연스러운 네이티브 구어(〜んですよ·〜かな·줄임말)가 같은 화제 안에서 번갈아 나옵니다.
- 한국 학습자에게 익숙한 소재(한국 음식·한국 가수·한국 공연)라 배경 지식 없이 바로 들립니다.
- **영상 삽입 재생을 착수 전에 헤드리스 브라우저로 확인**했습니다(정상 재생).

## 구성

```
mika-cards/
├─ Japanese-Mika640-Cards.html   앱 (단일 파일, 데이터·음원 내장)

├─ README.md
└─ src/
   ├─ raw/                     원본 공식 자막(ja·en)
   ├─ seg.py                   자막 큐 → 카드. ［화면 자막］ 분리, '- A - B' 두 화자 분리
   ├─ segs.json                분할 결과(자동)
   ├─ ko.txt                   id|한국어 뜻|읽기(히라가나)|주석|화자(S/M/C) — 직접 작성
   ├─ reading.py               fugashi(unidic-lite) 히라가나 읽기 자동 생성
   ├─ kanji.txt                한자 훈음 사전 437자
   ├─ words.txt                한자어 사전 455항목 (gen_words.py 로 생성)
   ├─ gen_words.py / lemma_meanings.py / lemma_base.py
   │                           lemma_base = frieren·milky 앱 사전에서 재사용한 168건
   ├─ study.txt                표현 45 · 단어 28
   ├─ make_audio.py            학습 음원(edge-tts, ja-JP-Nanami / ko-KR-SunHi)
   ├─ audio/                   mp3 146개 + index.json
   ├─ build.py                 최종 HTML 생성
   └─ tpl.html                 화면 템플릿(frieren-cards 계열, 학습법 탭은 이 영상에 맞게 교체)
```

## 재빌드

```bash
cd src
python3 gen_words.py > words.txt    # 사전 갱신 시
python3 build.py                    # seg.py 를 먼저 돌리고 HTML 생성
python3 make_audio.py               # 학습 음원(인터넷 필요) 후 build.py 재실행
```

## 번역·읽기에 대해

- **한국어 뜻**: 일본어 자막을 직접 번역했습니다(이 영상에는 내려받을 수 있는 한국어 자막 트랙이 없습니다).
- **히라가나 읽기**: fugashi 자동 생성 후 숫자·조수사(2合→にごう, 1日→いちにち), 인명·지명,
  문맥 독음(辛い→からい, この方→このかた)을 손으로 고쳤습니다.
- **공식 자막은 다듬어진 문장**입니다. 실제 발화에는 「えー」「なんか」 같은 군말이 더 많습니다.
  자막대로 외우면 깔끔한 회화체가 됩니다.
- **한자 풀이**: 본문 한자 434자 전부를 사전으로 커버했습니다(빌드가 누락을 검사).

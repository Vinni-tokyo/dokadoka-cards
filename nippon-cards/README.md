# 도카도카 일본어 공부 · ドカドカ日本語 — 斎藤友良「ニッポン」

YouTube 「ニッポン 日本語 賛美 Music Video」(ワーシップルーム, 2020-05, 5분 39초)로 만든
**일본어 찬양 학습 카드 앱**(한국어 학습자용). 34줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 8·단어 7.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- 斎藤友良 작사·작곡의 **일본 오리지널 찬양**입니다. 역대하 7장 14절을 노래로 만들었습니다.
  가사는 채널 설명란에 올린 것을 썼습니다.
- 1절과 2절이 같은 자리에서 마지막 줄만 바뀝니다(罪ゆるしこの地癒す ↔ 親しく聞いてくださる).
  へりくだる·慕い求める·立ち返る·〜てくださる 가 나오고, 후렴 「主よ救ってください」가 되풀이됩니다.

## 줄 시각

자막 트랙이 없어 **음성 인식(faster-whisper medium, 단어 시각)** 으로 맞췄습니다.
`tools/asr_words.py` → `tools/align_dp.py` 로 34줄을 순서 정렬했습니다(**34줄 전부 직접 대응**, 유사도 평균 0.80).
잘린 끝 시각은 `tools/fix_cue_ends.py` 로 보정했습니다. 박 그리드는 `beats.py` 로 구했습니다(BPM 142.2).

## 읽어주기 보정

`主` 가 자리에 따라 ぬし 로 읽혀 `src/tts_fix.txt` 에 `主|しゅ` 를 넣었습니다.

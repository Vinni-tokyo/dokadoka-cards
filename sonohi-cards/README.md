# 도카도카 일본어 공부 · ドカドカ日本語 — GROWING UP「その日全世界が」

YouTube 「その日全世界が」(GROWING UP - Topic, 앨범 『魂歌』 2007, 6분 28초)로 만든 **일본어 찬양 학습 카드 앱**(한국어 학습자용).
41줄(라이브 녹음 — 절 2번·후렴 5번·브릿지 1번). 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 16·단어 10.

## 원곡을 찾은 경위

요청받은 영상(UqtMVZQZn64)은 Clare Kasemset 의 일본어·영어 이중언어 **커버**였습니다.
설명란의 「作詞・作曲：長沢崇史」를 따라가 원곡을 찾았습니다.

- **GROWING UP「その日全世界が」**(2007, 앨범 『魂歌』) — 長沢崇史가 보컬로 있던 밴드의 원곡. 음반사 공식 음원(Topic). ← 이 앱
- 長沢崇史 개인 채널의 「その日全世界が ～ 約束の地」(2019) — 「約束の地」와 이은 메들리라 학습용으로는 원곡을 골랐습니다.

둘 다 앱 안 재생을 확인했습니다(`tools/embed_check.py` → OK).

## 가사

원곡 영상에는 자막도 설명란 가사도 없습니다. 교회 찬양팀 두 곳이 영상 설명란에 받아 적은 가사
(MakibA Worship, God Loves Japan 의 정정판)가 서로 일치해 그것을 썼습니다. 16줄을 실제로 부른 차례대로 펼쳐 41줄입니다.

## 줄 시각

자막이 없어 음성 인식으로 맞췄습니다. demucs 로 목소리만 떼어(`tools/vocal_segments` 방식) faster-whisper 로 받아쓰고
`tools/align_dp.py` 로 41줄을 순서 정렬했습니다(40줄 직접 대응). 라이브라 받아쓰기가 많이 뭉개져
(「叫べ王の王イエスに」→「叫べ 音を消すに」) 유사도는 낮지만 줄 순서가 정해져 있어 자리는 맞습니다.
받아쓰기 구간 경계와 어긋난 6줄은 손보정했습니다 — 1번(목소리 시작 15.5초)·14·22·32·40·41번.
박 그리드(BPM 135.4)는 라이브라 템포가 흔들려 반복 가사의 박 위치 편차가 큽니다(최대 3.7박). 마디 루프가 조금씩 밀릴 수 있습니다.

## 읽어주기 보정

| 본문 | 합성기가 읽던 소리 | 이 곡의 읽기 |
|---|---|---|
| わが神主よ | **かんぬし**(신관) | **かみ しゅ** |
| 主の御名高く | みな**だ**かく | みな **た**かく |

형태소 분석기도 같은 두 곳을 잘못 끊어(神主·名高い) 단어 사전에서 미리 띄웠습니다(`src/gen_words.py` 의 SPLIT).
主·御霊 은 제대로 읽고 있었습니다.

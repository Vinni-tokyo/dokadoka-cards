# 도카도카 일본어 공부 · ドカドカ日本語 — 銀河特急 ミルキー☆サブウェイ (전 7화)

YouTube 공식 채널(『銀河特急 ミルキー☆サブウェイ』本編, 各話 약 3분 30초)로 만든
**일본어 학습 카드 앱 시리즈**(한국어 학습자용). 전 7화, 화당 88~107장, 총 710장.

사회봉사활동으로 낡은 우주 열차를 청소하게 된 6명의 (전과) 범죄자들이 매회 사건에 휘말리는 코미디 애니메이션.
공식 채널이 자막을 **일본어·한국어·영어 3종 다 수동으로** 올려두어서, 지금까지 만든 애니 학습 콘텐츠 중
번역 품질이 가장 좋습니다(한국어 자막을 시간대 정렬해 번역의 기준으로 삼고, 부자연스러운 부분만 다듬었습니다).
속어·축약형·사투리 어미(〜べ, 〜っしょ, あーし=私 등)가 많은 빠른 구어체라 **중급 이상**에게 맞습니다.

- **입구**: `index.html` — 7화 목록. 각 화는 `Japanese-Milky<N>-Cards.html` 단일 파일.
- 카드·대본·학습(드릴/표현/단어) 탭 구성은 `yubisaki-cards/`·`bokuyaba-cards/` 와 동일(같은 템플릿 확장).

## ⚠️ 영상 재생 제한

이 시리즈는 저작권사(SHINEI ANIMATION)가 **외부 사이트로의 영상 삽입 재생(embed)을 차단**해 두었습니다.
그래서 카드에서 "이 장면 재생"을 눌러도 유튜브 플레이어가 `Video unavailable`을 표시하고,
"Watch on YouTube" 링크로 새 탭에서 여는 것으로 대체됩니다(템플릿이 원래 갖고 있던 오류 폴백 동작).
**카드 열람·읽기(히라가나)·뜻·한자/한자어 풀이·표현·단어 드릴·로컬 음원(원문·뜻) 반복 듣기는 전부 정상 동작**하며,
영상과 연동되는 기능(장면 자동 재생, 옆 카드 침범 방지 등)만 못 씁니다.
지금까지 만든 다른 앱들(ゆびさき, ぼくやば 등)은 이 제한이 없습니다 — 영상 채널마다 다릅니다.

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저로 `index.html`(7화 목록)을 엽니다(포트 8090). `file://` 로 열면 브라우저가
자체 보안 정책으로 리소스를 막을 수 있어 서버 실행을 권장합니다.

## 구성

```
milky-cards/
├─ index.html                       7화 목록(입구)
├─ Japanese-Milky1..7-Cards.html    화별 앱(단일 파일, 데이터·음원 내장)
├─ start.bat / start.sh
├─ README.md
└─ src/
   ├─ srtlib.py       srt 파싱 + '-' 대시로 화자별 발화 분리 + 시간 비례 보간
   ├─ seg.py           화별 분할 → epN/segs.json
   ├─ draft_ko.py      번역 초안 자동 생성(공식 ko 자막을 시간 겹침으로 정렬 + fugashi 자동 읽기) — 검수 전 출발점
   ├─ reading.py       fugashi(unidic-lite)로 히라가나 읽기 자동 생성(어절 단위 근사)
   ├─ kanji.txt        한자 훈음 사전(7화 공용, 492자)
   ├─ words.txt        한자어 사전(7화 공용, 506항목) — gen_words.py + lemma_meanings.py 로 자동 생성
   ├─ gen_words.py / lemma_meanings.py   words.txt 자동 생성기(표제어별 뜻 매핑 + kanji.txt 로 한자음 합성)
   ├─ check_cov.py     화별 한자 커버리지 검사(words.txt 가 본문 한자를 전부 커버하는지)
   ├─ make_audio.py    화별 학습 음원 생성(edge-tts, ja-JP-Nanami / ko-KR-SunHi)
   ├─ build.py         최종 HTML 생성(화 번호 인자로 선택, 기본 전체)
   ├─ tpl.html         화면 템플릿(yubisaki-cards 확장 — playback 룰·드릴·로컬 음원 포함)
   ├─ raw/epN/         원본 srt(ja·ko, 공식 자막)
   └─ epN/
      ├─ segs.json      분할 결과(자동)
      ├─ ko.txt         id|한국어 뜻|읽기(히라가나)|주석 — 공식 ko 자막 기준으로 검수·완성
      ├─ words.txt / kanji.txt   (공용 사전의 사본, build.py 가 읽음)
      ├─ study.txt      표현(E)·단어(V) 큐레이션
      └─ audio/         학습 음원(mp3) + index.json
```

## 재빌드

```bash
cd src
python3 seg.py                 # raw/epN/*.srt → epN/segs.json
python3 draft_ko.py             # (선택) epN/ko.txt 없을 때만 초안 생성
python3 gen_words.py > words.txt && cp words.txt kanji.txt epN/   # 사전 갱신 시
python3 check_cov.py ep1        # 한자 커버리지 확인(화별로 1~7 반복)
python3 build.py                # 전체 화 빌드 (인자로 화 번호 지정 가능: python3 build.py 1 3)
python3 make_audio.py           # 학습 음원 생성(edge-tts, 인터넷 필요) 후 build.py 재실행
```

## 번역·읽기에 대해

- **한국어 뜻**: 공식 한국어 자막을 시간대로 정렬해 기준으로 삼고, 화면 분할 방식이 달라 생긴 어색한 부분만 손으로 다듬었습니다.
- **히라가나 읽기**: fugashi(unidic-lite) 자동 분석 + 어절 단위 합침. 숫자·조수사(3日 등) 일부는 손으로 고쳤지만
  기계 분석 특성상 드물게 어색한 띄어쓰기나 오독이 남아 있을 수 있습니다.
- **화자 표시**: 방송 자막에 이름 태그가 없고(대시로 발화만 구분), 목소리를 직접 듣고 확인하지 않아
  등장인물별로 정확히 배정하기 어려워 전부 "화자 미상"으로 처리했습니다. 대신 대사 안에 이름이 나오는 곳(로 콜 장면 등)은
  본문 그대로 남겨 두어 문맥으로 유추할 수 있습니다.
- **한자 풀이**: 7화 전체에 나오는 한자 492자·한자어 506항목을 자동 추출해 훈음·뜻·한국 한자음을 달았습니다(수작업 매핑).

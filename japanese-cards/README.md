# 도카도카 일본어 공부 · ドカドカ日本語

YouTube 영상 「Snow Man 'Looking back 5 years' YouTube ver.」(Snow Man 공식 채널, 데뷔 5주년 회고 인터뷰)의
**공식 일본어 자막**으로 만든 **일본어 학습 카드 앱**(한국어 모어 학습자용).
대사 79장 + 화면 자막 26장 = 105장, 히라가나 읽기·한국어 뜻 병기.

`korean-cards/`(한국어 학습 앱)와 같은 구조로 만들었으며, 이 폴더만 통째로 복사하면 다른 PC에서 그대로 실행·재빌드됩니다.

---

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8098). Python 3 가 필요합니다.
(Windows 설치 시 `Add Python to PATH` 체크)

`Japanese-SnowMan105-Cards.html` 을 그냥 더블클릭해도 카드·대본·학습·편집은 쓸 수 있지만,
**YouTube 가 `file://` 에서의 임베드 재생을 거부**하므로(Error 153)
재생 버튼은 YouTube 를 해당 대사 시각부터 새 탭으로 엽니다.
페이지 안에서 재생하려면 위 실행기를 쓰세요.

어느 방식이든 **인터넷 연결**이 필요합니다(영상은 YouTube 에서 가져옵니다).

## 기능

- **카드** — 일본어 대사 + 히라가나 읽기(토글) + 한국어 뜻, 장면·화자별 필터, 체크 진도
- **화자** — 자막의 화자 표기를 그대로 살려 멤버 9명·팬·스태프별로 볼 수 있음
- **화면 자막** — 연도·행사를 설명하는 화면 자막 26줄도 카드에 포함(옵션으로 제외 가능)
- **대본** — 105줄 목록(시각·화자·대사·읽기·뜻), 줄 클릭 시 그 위치부터 재생, 재생 중 자동 추종
- **재생 구간 보정** — 「옆 카드 침범 금지」(기본 켜짐)로 붙어 있는 카드 사이에 앞뒤 대사가 새어 들어오지 않게 하고, 「시작 보정」(−0.3~+0.5초)과 카드별 「재생 구간 조정」(편집 박스: 시작/끝 ±0.3초, 「지금 위치로」)으로 자막 시각의 어긋남을 바로잡을 수 있음. 조정값은 브라우저에 저장되고 내보내기/가져오기에 포함
- **재생** — 대사 시작점으로 점프, 구간 반복, 다음 카드 자동 재생, 재생 여유(기본 0.5초)
- **드릴** — 학습 탭의 기본 화면. 유튜브 없이 단어·표현만 외우는 암기 드릴. 브라우저 내장 음성(TTS)으로 읽어 주고, 카드를 보고 떠올린 뒤 「몰라/애매/알아」로 채점하면 틀린 것은 같은 세션에서 곧 다시 나오고, 세션이 끝나면 0·1·3·7·14일 간격으로 다시 물어봄(브라우저에 저장). 방식은 日→韓 / 韓→日 / 듣기, 「자동 반복 듣기」는 손을 놓고 원문→뜻→원문 순으로 계속 읽어 줌. 「영상」 버튼으로만 원음을 들음
- **로컬 음원** — 표현·단어 전부에 Microsoft 신경망 음성으로 만든 mp3 를 앱 안에 심어 두었습니다(`src/audio/`, `tools/make_study_audio.py` 로 생성·증분 갱신). 드릴과 표현·단어 목록의 🔊/🔁 버튼, 「목록 전체 반복 듣기」, 드릴의 「반복 듣기」(1·2·3·5회, L 키)가 이 음원을 씁니다. 음원이 없는 항목만 브라우저 TTS 로 폴백
- **오늘** — 105장을 페이스(천천히 10 / 보통 15 / 빠르게 21 / 집중 35장)로 나눈 일일 분량. Day 별 대사·표현·단어 목록, 완료 표시, 「카드로」「오늘 퀴즈」 바로가기
- **학습** — 표현 40 · 단어 45. 각 항목이 나오는 자막 위치를 자동으로 찾아 예문·클립 재생 연결
- **퀴즈** — 표현/단어/대사/오늘 분량 × 日→韓 / 韓→日 / 듣기, 4지선다
- **학습법** — 4단계(듣기→확인→따라 하기→점검) 가이드와 팁 6가지. 학습 탭에서는 사이드바를 접고 화면을 넓게 씀
- **직접 편집** — 대사·읽기·뜻을 고쳐 저장(브라우저 저장). `내보내기`/`가져오기` 로 백업·이전

> 학습 기록(직접 수정한 내용)은 파일이 아니라 **브라우저**에 저장됩니다.
> 다른 PC 로 옮기려면 옮기기 전에 `내보내기`, 새 PC 에서 `가져오기` 하세요.
> 체크 진도와 설정은 아직 내보내기 대상이 아닙니다.

## 구성

```
japanese-cards/
├─ Japanese-SnowMan105-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh              실행기
├─ README.md
├─ WORKFLOW_PROMPT.md               제작 절차 프롬프트 (다른 에이전트용)
└─ src/                              재빌드 재료
   ├─ subtitles.srt                  원본 자막 (YouTube 공식 일본어 자막, yt-dlp 로 받음)
   ├─ seg.py                         자막 → 카드 분할 (화자 분리·화면 자막 추출)
   ├─ build.py                       최종 HTML 생성 (seg.py 를 먼저 실행)
   ├─ tpl.html                       화면 템플릿 (HTML/CSS/JS)
   ├─ ko.txt                         한국어 번역·읽기 105건  `id|뜻|읽기|주석`
   └─ study.txt                      학습 표현·단어 85건      `종류|일본어|읽기|뜻|메모`
```

## 재빌드

```bash
python3 src/build.py
```

`seg.py` → `build.py` 가 순서대로 돌고 `Japanese-SnowMan105-Cards.html` 을 덮어씁니다. 외부 라이브러리는 필요 없습니다.

번역·읽기를 고치려면 `src/ko.txt`, 학습 항목은 `src/study.txt` 를 편집한 뒤 다시 빌드하세요.
`ko.txt` 의 맨 앞이 카드 id 이고, id 는 `seg.py` 의 분할 결과에 대응합니다.
`study.txt` 의 항목은 자막에 활용형으로만 나와도(諦める → 諦めてません) 어간으로 자동 연결됩니다.

한국어 앱과 달리 **무음 컷(trim.py)·자막 교정(fixes.txt)은 없습니다.**
자동생성 자막이 아니라 공식 자막이라 타이밍이 정확하고 인식 오류가 없기 때문입니다.

`start.bat` 은 HTML 파일명을 안에 적어 두었으므로(`set PAGE=`),
파일명을 바꾸면 그 줄도 같이 고쳐야 합니다.

### 다른 영상으로 바꾸려면

```bash
yt-dlp --skip-download --write-subs --write-auto-subs --sub-langs ja --sub-format srt \
       --convert-subs srt -o "src/%(id)s.%(ext)s" "https://www.youtube.com/watch?v=<ID>"
```

받은 `.srt` 를 `src/subtitles.srt` 로 두고, `build.py` 의 `VID`·`SCENES`·`SPEAKERS` 를 고친 뒤
`ko.txt` 를 새 id 에 맞춰 다시 씁니다. `seg.py` 는 `Name: 대사` 형식의 화자 표기와 `［화면 자막］` 을 전제로 하므로
자동생성 자막(화자 없음)을 쓸 때는 `korean-cards/src/seg.py` 쪽 분할 규칙이 더 맞습니다.

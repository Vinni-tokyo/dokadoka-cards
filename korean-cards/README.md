# 도카도카 한국어 공부 · ドカドカ韓国語

YouTube 영상 「벼랑 끝에 프로미스나인 — 위험한 초대」의 자동생성 자막으로 만든
**한국어 학습 카드 앱**(일본어 모어 학습자용). 대사 383장, 일본어 뜻 병기.

이 폴더만 통째로 복사하면 다른 PC에서 그대로 실행·재빌드됩니다.

---

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다. Python 3 가 필요합니다.
(Windows 설치 시 `Add Python to PATH` 체크)

`Korean-Cliff389-Cards.html` 을 그냥 더블클릭해도 카드·대본·편집은 쓸 수 있지만,
**YouTube 가 `file://` 에서의 임베드 재생을 거부**하므로(Error 153)
재생 버튼은 YouTube 를 해당 대사 시각부터 새 탭으로 엽니다.
페이지 안에서 재생하려면 위 실행기를 쓰세요.

어느 방식이든 **인터넷 연결**이 필요합니다(영상은 YouTube 에서 가져옵니다).

---

## 기능

- **카드** — 한국어 대사 + 일본어 뜻, 장면별 필터, 체크 진도
- **대본** — 383줄 목록, 줄 클릭 시 그 위치부터 재생, 재생 중 자동 추종
- **재생** — 대사 시작점으로 점프, 구간 반복, 다음 카드 자동 재생
- **무음 컷** — 자막 끝의 비명·공백을 글자밀도로 추정해 제외(89장)
- **재생 여유** — 발화가 끝난 뒤 몇 초 더 재생할지(기본 1초)
- **교정** — 명백한 인식 오류 36건을 손봄. 자막 원문도 카드에 병기, 토글 가능
- **직접 편집** — 대사·뜻을 고쳐 저장(브라우저 저장). `내보내기`/`가져오기` 로 백업·이전

> 학습 기록(직접 수정한 대사)은 파일이 아니라 **브라우저**에 저장됩니다.
> 다른 PC 로 옮기려면 옮기기 전에 `내보내기`, 새 PC 에서 `가져오기` 하세요.
> 체크 진도와 설정은 아직 내보내기 대상이 아닙니다.

## 구성

```
korean-cards/
├─ Korean-Cliff389-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh          실행기
├─ README.md
└─ src/                          재빌드 재료
   ├─ subtitles.srt              원본 자막 (YouTube 자동생성)
   ├─ seg.py                     자막 → 카드 분할
   ├─ trim.py                    끝부분 무음 추정
   ├─ build.py                   최종 HTML 생성 (위 둘을 먼저 실행)
   ├─ tpl.html                   화면 템플릿 (HTML/CSS/JS)
   ├─ ja.txt                     일본어 번역 389건  `id|번역|주석`
   └─ fixes.txt                  자막 교정 36건      `id|교정문`
```

## 재빌드

```bash
python3 src/build.py
```

`seg.py` → `trim.py` → `build.py` 가 순서대로 돌고
`Korean-Cliff389-Cards.html` 을 덮어씁니다. 외부 라이브러리는 필요 없습니다.

번역을 고치려면 `src/ja.txt`, 자막 교정은 `src/fixes.txt` 를 편집한 뒤 다시 빌드하세요.
두 파일 모두 맨 앞이 카드 id 이고, id 는 `seg.py` 의 분할 결과에 대응합니다.

`start.bat` 은 HTML 파일명을 안에 적어 두었으므로(`set PAGE=`),
파일명을 바꾸면 그 줄도 같이 고쳐야 합니다.

# 도카도카 한국어 공부 · ドカドカ韓国語

YouTube 예능·토크 영상의 한국어 자막으로 만든 **한국어 학습 카드 앱**(일본어 모어 학습자용).
현재 **3편, 대사 963장**이 들어 있고 일본어 뜻이 병기됩니다.

| 시리즈 | 영상 | 대사 | 표현·단어 | 구간 |
|---|---|---:|---:|---:|
| 벼랑 끝에 프로미스나인 | `P7jpejjWGxM` | 383장 | 50·76 | 18 |
| 연희동 데이트 | `SAizVfA26Hk` | 306장 | 47·72 | 18 |
| 하냥카세 · 나경과 진솔한 대화 | `gyDLyMs2glk` | 274장 | 47·69 | 15 |

이 폴더만 통째로 복사하면 다른 PC에서 그대로 실행·재빌드됩니다.

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버(포트 8099)를 띄우고 브라우저를 엽니다. Python 3 가 필요합니다.
(Windows 설치 시 `Add Python to PATH` 체크)

상위 폴더의 `start.bat`/`start.sh`(포트 8100)로 열면 관문 페이지에서 다른 언어 앱과 함께 고를 수 있습니다.

> 실행기는 그 포트가 **정말 이 폴더를 서빙하는지 응답으로 확인**합니다.
> 200 이면 브라우저만 열고(서버 중복 방지), 아니면 빈 포트로 물러나 새로 띄웁니다.
> 폴더를 옮긴 뒤 낡은 서버가 살아남아 404 만 내던 문제를 막기 위한 것입니다.

`Korean-Cliff389-Cards.html` 을 그냥 더블클릭해도 카드·대본·학습·편집은 쓸 수 있지만,
**YouTube 가 `file://` 에서의 임베드 재생을 거부**하므로(Error 153)
재생 버튼은 YouTube 를 해당 대사 시각부터 새 탭으로 엽니다. 듣기 퀴즈도 이때는 잠깁니다.

어느 방식이든 **인터넷 연결**이 필요합니다(영상은 YouTube 에서 가져옵니다).

## 재생 구간을 정하는 방식

자동생성 자막은 끝시각이 발화 종료가 아니라 **다음 자막 시작점**인 경우가 많아(1편은 83%),
그대로 자르면 말이 끊기고, 그대로 늘리면 비명·공백까지 재생됩니다. 그래서:

```
시작 = 자막 시작 + 시작 보정(기본 0) + 카드별 조정
끝   = 발화 종료 추정점 + 여유(기본 0.5초) + 카드별 조정       (최소 1.2초 보장)
단, 옆 카드가 1초 안에 붙어 있으면 그 경계를 넘지 않는다 (「옆 카드 침범 금지」, 기본 켜짐)
```

**발화 종료 추정점**은 마지막 자막 조각의 글자밀도(초당 4.5자)로 계산하고,
빈 시간이 1.2초를 넘을 때만 깎습니다. 짧게 끄는 대사를 잘못 자르지 않기 위한 하한입니다.

예전에는 앞뒤에 0.2초씩 무조건 더했는데, 붙어 있는 카드(1편 382쌍 중 318쌍)에서 앞 대사 꼬리와
뒤 대사 머리가 새어 들어와 "구간이 잘못 잘린 느낌"이 났습니다. 지금은 붙은 카드끼리는 경계를 넘지 않고,
자막 전체가 이르거나 늦으면 「시작 보정」(−0.3~+0.5초)으로, 특정 카드만 어긋나면 편집 박스의
「재생 구간 조정」(시작/끝 ±0.3초, 「지금 위치로」)으로 맞춥니다. 조정값은 시리즈별로 브라우저에 저장되고
내보내기/가져오기에 포함됩니다.

## 구성

```
korean-cards/
├─ Korean-Cliff389-Cards.html   앱 (단일 파일 266 KB, 전 시리즈 데이터 내장)
├─ start.bat / start.sh          실행기
├─ README.md
└─ src/
   ├─ build.py                   빌드 (분할·무음추정·결합까지 이 한 파일)
   ├─ fetch.py                   영상 URL → 자막·메타 자동 준비 (yt-dlp)
   ├─ tpl.html                   화면 템플릿 (HTML/CSS/JS)
   └─ series/
      ├─ cliff389/
      │  ├─ meta.json            영상ID·제목·챕터·문장병합 지정
      │  ├─ subtitles.srt        원본 자막 (SRT)
      │  ├─ ja.txt               일본어 번역   `카드id|번역|주석`
      │  ├─ fixes.txt            자막 교정     `카드id|교정문`
      │  └─ study.txt            표현·단어     `E or V|한국어|일본어|메모`
      ├─ yeonhui/
         │  ├─ meta.json            `"source": "transcript"` 지정
         │  ├─ transcript.txt       원본 자막 (YouTube 자막 패널 형식)
         │  └─ ja.txt · fixes.txt · study.txt
      └─ hanyangkase/
         ├─ meta.json            `"source": "manual"` 지정 (fetch.py 가 자동으로 씀)
         ├─ subtitles.srt        채널이 붙인 정식 자막
         ├─ cards.txt            번역용 카드 목록 (빌드에는 안 쓰임)
         └─ ja.txt · fixes.txt · study.txt
```

## 재빌드

```bash
python3 src/build.py
```

`src/series/` 아래를 자동으로 훑어 전 시리즈를 다시 만들고
`Korean-Cliff389-Cards.html` 을 덮어씁니다. 외부 라이브러리는 필요 없습니다.

번역은 `ja.txt`, 자막 교정은 `fixes.txt`, 표현·단어는 `study.txt` 를 고친 뒤 다시 빌드하세요.
셋 다 맨 앞이 카드 id 이고, id 는 빌드의 분할 결과에 대응합니다.

### 시리즈 추가

**자동으로 가져오기**

```bash
python3 src/fetch.py <YouTube URL 또는 영상ID> <시리즈id>
```

루트 `.venv` 의 `yt-dlp` 로 한국어 자막과 메타데이터를 받아 `src/series/<id>/` 에
`subtitles.srt` · `meta.json`(영상에 공식 챕터가 있으면 그대로 포함) · `cards.txt`(번역용 카드 목록)를 만듭니다.
채널이 붙인 **정식 자막이 있으면 우선** 쓰고(`source: manual`), 없으면 자동생성 자막을 씁니다.
남는 일은 `ja.txt` · `study.txt` · `fixes.txt` 작성과 `meta.json` 의 일본어 라벨뿐입니다.

**손으로 넣기**

`src/series/<새이름>/` 폴더를 만들고 `meta.json` + 자막 + `ja.txt` + `study.txt` 를 넣으면
메인 화면에 자동으로 나타납니다. **코드는 건드릴 필요가 없습니다.**
재료가 덜 갖춰진 폴더는 빌드가 건너뛰고 무엇이 빠졌는지 알려줍니다.

자막은 두 형식을 지원합니다.

| `meta.json` 의 `source` | 파일 | 비고 |
|---|---|---|
| (없음) | `subtitles.srt` | DownSub 등에서 받은 SRT |
| `"transcript"` | `transcript.txt` | YouTube 자막 패널을 복사한 형식. 끝시각이 없어 다음 줄 시작으로 유추 |
| `"manual"` | `subtitles.srt` | 채널이 붙인 정식 자막. `>>`·공백이 없어 **종결어미**(-요/-다/-어/-잖아…)에서 문장을 나눔 |

`meta.json` 의 `chapters` 에는 **영상의 공식 챕터**를 넣으세요. 추측으로 구간을 나누면 틀립니다.
`merges` 는 길이 상한 때문에 문장 중간이 잘린 카드를 이어붙일 때 씁니다
(분할을 다시 하면 id 가 밀려 번역 대응이 깨지므로, 빌드 단계에서 병합합니다).

`start.bat` 은 HTML 파일명을 안에 적어 두었으므로(`set PAGE=`),
파일명을 바꾸면 그 줄도 같이 고쳐야 합니다.

## 알아둘 점

- **ドリル / 드릴** — 学習タブの基本画面。YouTube に頼らず単語・表現だけを覚える暗記ドリル。ブラウザ内蔵の音声(TTS)で読み上げ、カードを見て思い出してから「わからない/あいまい/わかる」で採点すると、間違えたものは同じセッション内ですぐ再登場し、セッション後は 0・1・3・7・14 日の間隔で再出題(ブラウザに保存)。方式は 韓→日 / 日→韓 / 聞き取り、「自動でくり返し聞く」は手放しで 原文→意味→原文 の順に読み続ける。「動画」ボタンでのみ元の音声を聞く
- **학습 기록은 브라우저에 저장됩니다.** 직접 수정한 대사는 `내보내기`/`가져오기` 로 옮길 수 있지만,
  **체크 진도와 설정은 아직 내보내기 대상이 아닙니다.**
- **자막에 인식 오류가 남아 있습니다.** 명백한 것(1편 36건·2편 25건)은 교정했고, 정식 자막인 3편은 인식 오류 대신 자막의 멋부린 표기(`잤눈뒈` 등) 7건만 표준형으로 바꿨으며, 자막 원문도 카드에 병기했지만,
  확신이 서지 않는 것은 일부러 남겨 두었습니다. 화면의 `편집` 으로 직접 고칠 수 있습니다.
- **구간 안의 개별 대사가 누구 말인지는 알 수 없습니다.** 자막에 화자 정보가 없습니다.
  1편은 공식 챕터 덕분에 멤버별 인터뷰 구간만 구분해 두었습니다.

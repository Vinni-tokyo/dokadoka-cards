# 도카도카 한자 카드 · 설계서

> 사이트의 일본어 영상 앱 7편에서 나온 한자·한자어만 모아 따로 외우는 **한자 학습툴**. 2026-09-13 초안.
> 참고 화면: 시판 한자 앱의 「5급5장1회독 0/250 · かえす / 返す / 돌려주다 · 공부하겠음 | 알고있음」.

---

## 1. 한 줄 정의

**영상에서 이미 만난 한자만** 카드로 뽑아, 참고 화면과 같은 「모름/앎 두 버튼 회독」으로 돌린다.
사전 앱과 달리 모든 카드가 **내가 본 대사**로 되돌아간다(예문 = 실제 대사, 버튼 하나로 그 장면 재생).

## 2. 데이터 원천 (실측, 2026-09-13)

각 일본어 앱은 빌드 때 카드마다 `kj` 필드를 만든다: `[표제어, 독음, 뜻, 한국 한자음, [[漢字, 훈음], …]]`.
원본은 앱마다 `src/words.txt`(한자어 사전)와 `src/kanji.txt`(훈음 사전)이고 빌드가 누락을 검사하므로 품질이 보장된 상태다.

| 항목 | 값 |
|---|---|
| 대상 앱 | 僕やば · First Love · 프리렌(22회) · 하츠코이 · 미카 · 밀키 · ゆびさき (7편) |
| kj 있는 카드 | 1,718장 / 일본어 카드 2,366장 |
| 고유 한자 | **964자** (1회만 등장 327자) |
| 고유 한자어 | **1,433개** (2회 이상 등장 634개) |
| 빈출 상위 | 人113 一78 今76 思76 私75 何75 本74 日66 歌63 分63 |
| 훈음 불일치 | 17자 (예: 常 「떳떳할 상/항상 상」, 女 「계집 녀/여자 녀」) → 통일 파일로 해결 |

**제외** · SnowMan(japanese-cards)은 `kj` 가 없다(사전 파일 미작성). 사전을 쓰면 자동 편입.
**없는 것** · JLPT 급수는 데이터에 없다. v1 은 사이트 빈도로 등급을 매긴다.

### 2-1. 한국어 한자 · 부수 · 세부 한자 (외부 사전 2종, 실측 2026-09-13)

| 사전 | 라이선스 | 여기서 쓰는 것 | 964자 커버 |
|---|---|---|---|
| **Unihan** (Unicode 17) | Unicode License (표기만) | 부수 번호·획수 `kRSUnicode/kTotalStrokes` · 한국음 `kHangul` · 일본 음독/훈독 `kJapanese` | 부수·획수 963 (々 제외) · 한국음 852 |
| **KanjiVG** r20250816 | CC BY-SA 3.0 | 구성 요소 트리 `kvg:element`(재귀) · 부수 표시 `kvg:radical` · 위치 `kvg:position` · **획순 path** | **964 / 964** |
| `src/kyujitai.txt` (직접 작성) | — | 신자체→정자체 115자 (気→氣, 体→體, 円→圓 …) | 한국음 없던 112자 중 109자 회복 |

- 한국음이 없는 112자는 전부 한국에서 안 쓰는 **일본 신자체**였다. 정자체로 바꿔 Unihan 을 다시 찾으면 붙고, 남는 것은 込·働·丼 일본 국자 3자뿐(훈음의 음을 그대로 씀).
- 같은 대조로 사내 훈음 오류도 잡혔다: 摺 「끌 인」(→ 접을 접), 魅 「매혹할 매丁|고무래 정」(데이터 깨짐) 등 9건. 빌드가 **훈음의 음 ≠ Unihan 한국음**이면 경고한다.
- KanjiVG 구성 트리 예: 返 = 反(厂 + 又) + ⻌[부수] · 魔 = 麻(广 + 林) + 鬼 · 歌 = 哥(可 + 可) + 欠[부수]. 1단계 구성이 2개 이상인 한자 879, 단일체 46.
- 구성 요소 552종 중 204종이 이 사이트의 한자라서, 세부 한자를 누르면 **그 한자 카드로 이동**할 수 있다. 나머지(亻·氵·宀 같은 변·머리)는 이름만 보여 준다(변 이름표 `src/parts.txt` 직접 작성, 약 60개).
- 획순: KanjiVG path 를 순서대로 그리면 되므로 **쓰기 연습(획순 애니메이션)도 가능**해졌다(11절에서 제외했던 항목을 v1 에 포함).

## 3. 덱 체계 (참고 화면의 「급 · 장 · 회독」에 대응)

- **급** = 사이트 등장 빈도 5등급. 1급이 가장 자주 나온 한자.

  | 급 | 기준(등장 횟수) | 한자 수 |
  |---|---|---|
  | 1급 | 20회 이상 | 63 |
  | 2급 | 8~19회 | 141 |
  | 3급 | 3~7회 | 272 |
  | 4급 | 2회 | 161 |
  | 5급 | 1회 | 327 |

- **작품** = 7편 중 하나. 「프리렌에 나온 한자만」처럼 영상 하나를 다 본 뒤 정리하는 용도.
- **장** = 덱을 50장씩 자른 묶음(1급 2장, 3급 6장 …). 참고 화면의 「5장」에 해당.
- **회독** = 같은 장을 다시 도는 횟수. 1회독은 전부, 2회독부터는 직전 회독에서 「공부하겠음」 누른 카드만. 0장이 되면 그 장 완료.

## 4. 카드 두 종류

| | 단어 카드 (기본) | 한자 카드 |
|---|---|---|
| 앞면 | **返す** 만 크게 | **返** 만 크게 |
| 뒷면 | 위 かえす · 아래 **돌려주다** · 한자음 「반」 · 한자별 훈음 「돌이킬 반」 | 훈음 **돌이킬 반** · 한국 한자 「返 반」(정자체가 다르면 「気 → 氣 기」) · 부수 ⾡ 책받침 · 7획 · 구성 反(厂+又)+⻌ · 음독 ヘン/훈독 かえす · 이 사이트의 단어 8개 · 등장 횟수 |
| 예문 | 실제 대사 1줄 + 한국어 뜻 + 「▶ 장면」 | 단어를 누르면 그 단어 카드로 |
| 수 | 1,433 | 964 |

앞면에서 화면을 누르면 뒷면(읽기·뜻)이 열리고 그 다음에 두 버튼을 누른다.
참고 화면처럼 처음부터 다 보이게 하는 「전부 보기」 스위치도 둔다(1회독 분류용).

## 5. 화면 (모바일 1열, 스크롤 없이 한 화면)

```
┌─────────────────────────────┐
│ ≡   1급 2장 · 1회독   0/50  ✕ │  ← 헤더: 덱 이름 · 진행 · 닫기
│ no.14        공부시간 02:39  │  ← 번호 · 이번 세션 타이머
│                             │
│           かえす            │  ← 뒷면에서만
│            返す             │  ← 앞면 (탭하면 뒷면)
│          돌려주다            │
│      返 돌이킬 반 · 음 반     │
│                             │
│ 「借りた本を返す」 빌린 책을… │  ← 실제 대사 · ▶ 장면
│                             │
│ [ ? 공부하겠음 ] [ ✓ 알고있음 ]│  ← 하단 고정, 엄지 영역
└─────────────────────────────┘
```

1. **덱 선택** — 급 5개 · 작품 7개 카드 목록. 각 덱에 「장 진행 2/6 · 남은 카드 37」.
2. **카드** — 위 그림. 스와이프 좌(공부하겠음)/우(알고있음)도 같은 동작.
3. **한자 상세** — 카드의 한자를 누르면 시트가 올라옴. 위에서 아래로:
   - 큰 한자 + **훈음** + 한국 한자(정자체·한국음) + 부수·획수
   - **구성** — 세부 한자를 칩으로 (返 = 反 + ⻌, 反 = 厂 + 又). 사이트에 있는 한자는 칩이 눌리고 그 한자 상세로 이동, 변·머리는 이름만(⻌ 책받침)
   - **획순** — 작은 SVG 에 획을 차례로 그림(▶ 버튼, 0.4초/획). 「따라 쓰기」는 v1 범위 밖
   - 음독·훈독 (Unihan `kJapanese`) · **한국어 한자어** 2개(返還 반환 · 返納 반납, `src/hanja_ko.txt` 직접 작성 964자)
   - 이 사이트의 단어들 · 작품별 등장
4. **회독 결과** — 장이 끝나면 「알고있음 41 · 공부하겠음 9 → 2회독 시작」.
5. **복습함** — 「공부하겠음」 누적 목록. 여기서 바로 카드 모드로.

## 6. 학습 흐름과 저장

- 진행은 `localStorage['kanji']` 한 키에 `{deck: {chapter: {round, idx, know:[], study:[]}}, time:{date:sec}}`.
- 「알고있음」은 그 장의 이번 회독에서 빠진다. 「공부하겠음」은 다음 회독의 덱이 된다.
- 어느 덱에서 알았든 **카드 단위 기억**도 둔다(`seen[word]=know|study`). 작품 덱에서 안 것은 급 덱에서도 「앎」 표시.
- 공부시간은 카드가 떠 있는 동안만 센다(탭 전환·백그라운드 정지).
- 내보내기/가져오기 JSON(기존 앱과 같은 방식).

## 7. 파이프라인

```
kanji-cards/
├─ Kanji964-Cards.html        단일 파일 (데이터 내장, 외부 라이브러리 없음)
├─ start.sh / start.bat       포트 8084
├─ README.md · DESIGN.md
└─ src/
   ├─ build.py       ../*/Japanese-*Cards.html 의 DATA.kj 를 전부 읽어 한자·단어 표를 만들고 사전 2종을 붙여 tpl 에 심음
   ├─ fetch.py       Unihan.zip · kanjivg.xml.gz 를 받아 964자 분만 src/dict.json 으로 추림 (원본은 리포에 넣지 않음, 추린 것만 커밋)
   ├─ dict.json      한자별 {부수, 획수, 한국음, 음독, 훈독, 구성 트리, 획순 path}  ← fetch.py 산출
   ├─ kyujitai.txt   신자체→정자체 115자 `신|정` (작성 완료, 검증됨)
   ├─ hanja_ko.txt   한국어 한자어 예 `漢字|한자어 음|한자어 음` (직접 작성, 1·2급 204자 먼저)
   ├─ parts.txt      변·머리 이름 `⻌|책받침` 약 60개 (직접 작성)
   ├─ hun.txt        훈음 통일·교정 `漢字|훈음` (불일치 17자 + Unihan 대조 오류 9자)
   └─ tpl.html       화면
```

- 원천을 **빌드 결과물(HTML) 에서 읽는** 이유: 카드 id·시각·교정된 본문이 거기에만 있다. 각 앱을 다시 빌드하면 `python3 src/build.py` 한 번으로 따라온다.
- 예문 선택: 그 단어가 나온 카드 중 8~40자인 가장 짧은 대사.
- 획순 path 는 964자 × 평균 10획 ≈ 1.1MB. 앱이 단일 파일이라 그대로 심되 좌표를 소수 1자리로 줄여 약 0.6MB 로 맞춘다.
- 출처 표기: 화면 하단과 README 에 Unihan(Unicode License)·KanjiVG(CC BY-SA 3.0) 를 적고, KanjiVG 파생물이므로 앱 자체도 CC BY-SA 로 표시한다.
- 「▶ 장면」 링크: `../frieren-cards/Japanese-Frieren12-Cards.html#c4`. **일본어 앱 7편의 템플릿에 `#c<id>` 해시로 해당 카드를 여는 처리(10줄)를 추가해야 한다.** 지금은 어느 앱에도 없다.

## 8. 화면 규칙 (기존 앱과 동일)

- 색·글꼴 토큰은 일본어 앱과 같이 씀(`--brand #3b4a7a`, `--accent #b0603f`). 참고 화면의 청록 헤더는 따르지 않는다.
- ≤600px: 버튼 2개 하단 고정(높이 64px), 카드 본문은 남은 높이 안에서 세로 가운데, 스크롤 없음.
- `minmax(0,1fr)` · `notranslate` 메타 · 다크 모드는 기존 앱 수준.
- 한자는 `lang="ja"` 로 일본 글꼴 형태 보장(直·今 등 한중일 차이).

## 9. 관문·문서

- `index.html` 일본어 섹션 맨 위에 `kind:'한자 · 漢字'` 항목 1개(영상 없음 → 썸네일 대신 큰 「漢」 글자).
- 루트 README 폴더 지도 · WORKFLOW_PROMPT 앱 목록에 한 줄.

## 10. 완료 기준 (검증 가능한 것만)

1. 빌드가 7편의 kj 를 전부 읽어 **한자 964 · 단어 1,433** 을 출력하고, 훈음 불일치 0.
2. 412px 폭에서 카드 화면이 **스크롤 없이** 들어가고 가로 넘침 없음(headless 캡처).
3. 1급 1장을 끝까지 돌렸을 때 결과 화면의 합이 50이고, 새로고침 후 2회독이 「공부하겠음」 수만큼만 남음.
4. 「▶ 장면」이 프리렌 12회 4번 카드를 열고 그 위치부터 재생(해시 처리 추가 후).
5. 964자 전부에 부수·획수·구성 트리·획순이 있고, 한국음 없는 한자가 込·働·丼 3자뿐.
6. 훈음의 음 ≠ Unihan 한국음 경고 0건(정자체 경유 포함).
7. 返 상세에서 구성 칩 「反」을 누르면 反 상세로 가고, ⻌ 는 「책받침」 이름표만 뜸.
8. `node --check` 통과, 관문에서 열림.

## 11. 후속 (v1 범위 밖)

- JLPT 급수·획수·음독/훈독: KANJIDIC2(CC BY-SA 4.0) 결합. 등급 기준을 「JLPT」로 바꿔 끼울 수 있게 `lv` 필드만 갈아끼우는 구조로 둔다.
- SnowMan 앱 사전(words.txt·kanji.txt) 작성 → 자동 편입.
- 따라 쓰기(손가락 궤적 채점)는 제외. 획순 보기까지만 v1.

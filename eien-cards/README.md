# 도카도카 일본어 공부 · ドカドカ日本語 — 4.5Music「永遠の御名」

YouTube 「I AM/永遠の御名 - Original Japanese Worship」(4.5Music, 2026-04, 5분 2초)로 만든
**일본어 찬양 학습 카드 앱**(한국어 학습자용). 52줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 20·단어 15.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- **공식 채널에 일본어·한국어 자막이 둘 다 붙어 있고 52줄이 그대로 맞물립니다.** 4.5Music 의 오리지널 곡입니다.
- 출애굽(유월절·홍해)과 십자가를 **같은 꼴로 겹쳐** 놓았습니다. 「遣わして 民を救う」가 모세(9번 줄)와
  예수(24번 줄) 자리에 두 번 나오고, 「血が塗られた戸口」(10)와 「血に染まった十字架」(25)가 짝을 이룹니다.
- 御名(みな)·代々(よよ)·民(たみ)·子羊(こひつじ) 같은 **성경 어휘의 읽기**와
  수동·사역·존경(守られる·終わらせて·告げられた)이 고루 나옵니다.
- 제목 I AM 은 40번 줄 「わたしはある」(출애굽기 3장)에서 옵니다.

## 줄 시각

공식 자막 두 벌에서 만들었습니다. 시각은 손대지 않았습니다. 박 그리드는 `beats.py` 로 구했습니다(BPM 114.7).

## 읽어주기가 잘못 읽던 한자

| 본문 | 합성기가 읽던 소리 | 이 곡의 읽기 |
|---|---|---|
| 御名 | **ぎょめい** | **みな** |
| 代々 | **だいだい** | **よよ** |
| 主 | (자리에 따라 ぬし) | しゅ |

`tools/check_reading.py` 로 짚고 `tools/hear_tts.py` 로 실제 소리를 재어 가린 것만 `src/tts_fix.txt` 에 적었습니다.
같이 짚힌 民(たみ)·何より(なにより)·地(ち)는 제대로 읽고 있어 건드리지 않았습니다.
「約束の地」의 地는 형태소 분석기가 기호로 보아 사전에서 빠져, `gen_words.py` 의 EXTRA 에 손으로 넣었습니다.

# 도카도카 영어 공부 · Fei-Fei Li on The Circuit

YouTube 영상 「What's Beyond ChatGPT? The 'Godmother of AI' Has a Plan | The Circuit」(Bloomberg Originals 공식, 2026-08-19, 24분 4초)의
**Bloomberg 공식 영어 캡션**으로 만든 **고급 영어 학습 카드 앱**(한국어 모어 학습자용).
대사 250장, 한국어 뜻·주석 병기(주석 202장), 자막 오기 교정 4장.

에밀리 창이 진행하는 다큐형 인터뷰입니다. 컴퓨터 비전의 개척자 페이페이 리의 어린 시절과 이민, ImageNet, 'AI 의 대모'라는 호칭, World Labs 창업과 월드 모델·Marble 시연, 로봇·경쟁·회의론, 학생과 미국의 AI 정책, 신 콤플렉스와 거버넌스, 낙관론과 UFO 까지 이어집니다.
**내레이션(압축된 서술문) · 진행자의 짧은 질문 · 리 박사의 틀 잡기 답변**, 세 층위의 말투가 한 편에 들어 있는 것이 특징입니다. 같은 폴더의 젠데이아 인터뷰(`english-cards/`)보다 어렵고, 올트먼 인터뷰(`altman-cards/`)보다 문장은 짧지만 어휘 폭이 넓습니다.

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8094). Python 3 가 필요합니다.
`English-FeiFei250-Cards.html` 을 그냥 더블클릭하면 카드·대본·학습·편집은 쓸 수 있지만 YouTube 가 `file://` 임베드를 거부하므로(Error 153) 재생 버튼은 YouTube 를 해당 시각부터 새 탭으로 엽니다. 어느 방식이든 인터넷 연결이 필요합니다.

## 기능

- **카드** — 영어 대사 + 한국어 뜻(가리기/보기) + 주석, 장면·화자별 필터, 체크 진도
- **화자** — 리 140장 · 에밀리 창 58장 · 내레이션 42장 · 저스틴 존슨(공동창업자) 6장 · 무대 안내 2장 · 에릭 슈밋(자료 영상) 1장 · 학생들(자료 영상) 1장. 캡션에 화자 표시가 없어 `src/turns.txt` 에 121곳의 전환 지점을 직접 지정
- **장면** — 화제별 12장면(산책 → 어린 시절 → ImageNet → 대모 호칭 → 창업 → 월드 모델 → Marble → 무대 대담 → 초기 분야 → 학생·정책 → 위험·거버넌스 → 미래·UFO)
- **대본** — 250줄 목록, 줄 클릭 시 그 위치부터 재생, 재생 중 자동 추종
- **재생 구간 보정** — 「옆 카드 침범 금지」(기본 켜짐)로 붙어 있는 카드 사이에 앞뒤 대사가 새어 들어오지 않게 하고, 「시작 보정」(−0.3~+0.5초)과 카드별 「재생 구간 조정」(편집 박스: 시작/끝 ±0.3초, 「지금 위치로」)으로 자막 시각의 어긋남을 바로잡을 수 있음. 조정값은 브라우저에 저장되고 내보내기/가져오기에 포함
- **재생** — 대사 시작점으로 점프, 구간 반복, 다음 카드 자동 재생, 재생 여유
- **드릴** — 학습 탭의 기본 화면. 유튜브 없이 단어·표현만 외우는 암기 드릴. 브라우저 내장 음성(TTS)으로 읽어 주고, 카드를 보고 떠올린 뒤 「몰라/애매/알아」로 채점하면 틀린 것은 같은 세션에서 곧 다시 나오고, 세션이 끝나면 0·1·3·7·14일 간격으로 다시 물어봄(브라우저에 저장). 방식은 EN→韓 / 韓→EN / 듣기, 「자동 반복 듣기」는 손을 놓고 원문→뜻→원문 순으로 계속 읽어 줌. 「영상」 버튼으로만 원음을 들음
- **오늘** — 250장을 페이스(천천히 18 / 보통 25 / 빠르게 36 / 집중 50장)로 나눈 일일 분량. 보통 기준 10일 완성
- **학습** — 표현 103 · 단어 76. 각 항목이 나오는 자막 위치를 자동으로 찾아 예문·클립 연결
- **퀴즈** — 표현/단어/대사/오늘 분량 × EN→KO / KO→EN / 듣기, 4지선다
- **학습법** — 4단계 가이드와 팁 6가지(내레이션·질문·답변의 세 층위 말투 등 이 영상에 맞춰 씀)
- **직접 편집** — 대사·뜻을 고쳐 저장(브라우저 저장). 내보내기/가져오기로 백업

## 구성

```
feifei-cards/
├─ English-FeiFei250-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh           실행기
├─ README.md
└─ src/
   ├─ subtitles.srt               원본 자막 (Bloomberg 공식 영어 캡션 `en`, yt-dlp 로 받음)
   ├─ turns.txt                   화자 전환 지점 121곳  `구절|화자`
   ├─ fixes.txt                   자막 오기 교정 4장     `id|교정문` (원문은 raw 로 보존)
   ├─ seg.py                      자막 → 카드 분할 (altman-cards 와 동일)
   ├─ build.py                    최종 HTML 생성 (seg.py 를 먼저 실행, 파일명의 숫자 = 카드 수)
   ├─ tpl.html                    화면 템플릿
   ├─ ko.txt                      한국어 번역·주석 250건  `id|뜻|주석`
   └─ study.txt                   학습 표현·단어 179건    `종류|영어|뜻|메모`
```

## 재빌드

```bash
python3 src/build.py
```

### 이 자막 형식의 특징 (seg.py)

- 큐가 문장 중간에서 끊기고 **화자 표시가 없습니다**. 큐를 전부 이어 붙여 문장 끝과 `turns.txt` 의 화자 전환 구절에서 자르고, 글자 위치 ↔ 큐 시각 대응표로 재생 시각을 보간합니다.
- 다큐라 화자가 7명이고 내레이션과 진행자(같은 사람의 목소리)가 번갈아 나옵니다. 내레이션은 서술문, 진행자는 질문이라 내용으로 구분해 지정했습니다.
- `What's it like running your own shop?` 처럼 같은 문장이 두 번 나오는 곳은 뒤에 이어지는 말까지 붙여 전환 구절을 유일하게 만들었습니다. `Dr. King` 의 마침표는 문장 끝으로 보지 않습니다.
- 캡션 오기(`Marbel`, `wrld`, `let's now throw the baby`, `[OpenAI's]`) 4장을 `fixes.txt` 로 고쳤습니다. 원문은 데이터의 `raw` 에 남습니다.

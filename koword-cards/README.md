# 도카도카 한국어 단어·표현 카드 · 単語カード

이 사이트의 **한국어 영상 앱 6편**(벼랑 끝에 프로미스나인 · 하냥카세 · 연희동 데이트 · 사랑하기 때문에 · Supersonic · Vitamin ME)에
나온 **표현 198 · 단어 257 = 455개**만 모아 따로 외우는 학습툴입니다.
영상 앱과 달리 유튜브 없이 돌아가고, 모든 카드가 **내가 본 대사**로 되돌아갑니다(예문 = 실제 대사, 「▶ 장면」으로 그 장면 재생).

`kanji-cards`(일본어 한자 카드)의 한국어판이며 회독 방식이 같습니다.

---

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

포트 8106. 「▶ 장면」이 `../` 로 옆 폴더의 영상 앱을 열기 때문에 **상위 폴더를 서빙**합니다.
유튜브를 쓰지 않으므로 `Korean-Words455-Cards.html` 을 그냥 열어도 카드·검색·상세는 다 됩니다(그때는 「▶ 장면」만 안 열립니다).

## 쓰는 법

1. **덱**을 고른다 — 전체 / 표현 / 단어 / **발음 주의** / 작품별 / 문형별 / 복습함.
   덱 안에서는 **이 사이트에 자주 나온 순서**입니다(한자 앱의 JLPT 급수 자리).
2. **장**(기본 15개, 홈에서 5~50 조절)을 연다.
3. 앞면은 한국어만. **화면을 누르면** 뜻·주석·실제 대사가 열린다(처음부터 보이게 하려면 홈의 체크박스).
4. **공부하겠음 / 알고있음** 을 누른다 — 스와이프 좌/우, 키보드 ←/→, 스페이스(뜻 보기) 도 됩니다.
5. 장이 끝나면 결과가 뜨고, **2회독**부터는 「공부하겠음」 누른 카드만 남습니다. 0장이 되면 그 장 완료.
6. 「공부하겠음」은 **복습함**에 모입니다.

**거꾸로 모드** · 홈에서 켜면 일본어 뜻이 앞면, 한국어가 뒷면이 됩니다(산출 연습).

**목록·검색** · 오른쪽 위 돋보기. 455개를 한국어·일본어·주석으로 즉시 찾고, 표현/단어/발음/공부하겠음/알고있음으로 거릅니다.
항목을 누르면 **상세 시트** — 발음 · 뜻 · 주석 · 실제 대사(그 말에 색 표시) · **▶ 장면** · 나온 곳(작품별 횟수) · 같은 문형 · 내 표시.

진행(회독·앎/공부 표시)은 브라우저에 저장되고 **내보내기/가져오기**로 옮길 수 있습니다.

## 발음 표시 (철자와 소리가 다른 81개)

한국어는 적는 대로 읽지 않습니다. `괜찮아[괜차나]` `습관[습꽌]` `감독님[감동님]` `많이[마니]`.
455개에 **표준발음법 규칙**(연음 · 겹받침 · ㅎ 축약/탈락 · 비음화 · 유음화 · 경음화 · 구개음화)을 적용해
**소리가 달라지는 81개(18%)** 를 골라 <b>발음</b> 표시를 달았습니다. 덱 「발음 주의」로 그것만 돌 수 있습니다.

> **한계** · 규칙만으로 계산하므로 **사전이 필요한 두 가지는 못 합니다** — 합성어 경계(`한여름`은 [한녀름]인데 [하녀름]으로 계산)와
> 한자어 경음화(`활동`은 [활똥]인데 그대로). 표준 예제 39개 중 37개, 실제 항목 표본 30개 중 29개가 맞았습니다.
> 실패 방식은 대체로 **규칙을 덜 적용하는 쪽**(틀린 소리를 지어내지 않음)입니다.

급수 목록 원본(xlsx)은 리포에 담지 않습니다. `python3 src/fetch.py` 가 내려받아
이 앱에 실제로 쓰이는 196개분만 `src/levels.json`(7 KB) 으로 추려 둡니다.
455개 중 259개는 목록 밖(구어 강조어·외래어·고유명사 등)이라 「급수 외」로 묶고 이 앱에 자주 나온 순서로 둡니다.

## 구성

```
koword-cards/
├─ Korean-Words455-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh
├─ README.md
└─ src/
   ├─ build.py    ../*-cards/Korean-*.html 의 STUDY 를 모아 중복 제거·발음·예문·출처를 붙여 앱 생성
   ├─ pron.py     한글 철자 → 표준 발음 (자체 검증 예제 39개 포함, `python3 src/pron.py` 로 실행)
   └─ tpl.html    화면 (HTML/CSS/JS)
```

## 재빌드

```bash
python3 src/pron.py     # 발음 엔진 자체 검증
python3 src/build.py    # 앱 생성
```

한국어 영상 앱이 늘거나 `study.txt` 가 바뀌면 **다시 빌드하기만 하면** 항목 수와 파일명이 따라 바뀝니다(`Korean-Words<N>-Cards.html`).
새 한국어 앱을 추가할 때 따로 등록할 일은 없습니다 — `../*-cards/Korean-*.html` 을 자동으로 훑습니다.

> 「▶ 장면」은 `../<앱>/<페이지>#<시리즈>/c<카드id>` 로 엽니다.
> 이를 위해 한국어 영상 앱 4종에 **카드 단위 해시 링크**를 더했습니다(기존 `#<시리즈>` 도 그대로 동작).

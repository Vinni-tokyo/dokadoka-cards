# 도카도카 일본어 공부 · ドカドカ日本語 — 4.5Music「いつくしみ深き」

YouTube 「What A Friend We Have In Jesus/いつくしみ深き - Japanese Worship」(4.5Music, 4분 10초)로 만든
**일본어 찬양 학습 카드 앱**(한국어 학습자용). 24줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 12·단어 10.
한국 찬송가로는 「죄짐 맡은 우리 구주」.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- **공식 채널에 일본어·한국어 자막이 둘 다 붙어 있고 24줄이 그대로 맞물립니다.** 음성 인식을 쓰지 않았습니다.
- **문어(文語) 찬송가**입니다. 〜たもう·〜たまわん·〜ず·〜ぬ·深き·知りて 같은 옛 어미가 짧은 줄로 나와
  한 줄에 하나씩 익힐 수 있습니다.
- 3절이 모두 「いつくしみ深き 友なるイエスは」로 열리고 뒤만 바뀝니다. 2번 줄 「友なるイエス」와
  21번 줄 「世の友」가 맞섭니다.

## 줄 시각·한국어 뜻

공식 자막 두 벌에서 만들었습니다. 시각은 손대지 않았습니다.
한국어 자막은 한국 찬송가 가사(의역)라, **뜻은 일본어를 그대로 옮기고** 찬송가 가사는 주석에 적었습니다
(`src/_ko_official.txt` 가 공식 자막입니다). 박 그리드는 `beats.py` 로 구했습니다(BPM 130.0).

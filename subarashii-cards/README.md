# 도카도카 일본어 공부 · ドカドカ日本語 — 中山告「素晴らしい主を」

YouTube 「Goodness Of God (Japanese) 素晴らしい主を」(Tsuguru Nakayama 中山告, 2020-05, 4분 52초)로 만든
**일본어 찬양 학습 카드 앱**(한국어 학습자용). 32줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 13·단어 7.
한국어 찬양으로는 「선하신 하나님」.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- **공식 채널에 일본어 자막이 붙어 있어** 32줄 시각을 그대로 썼습니다. 음성 인식을 쓰지 않았습니다.
  한국어 자막은 없어서 뜻·읽기·주석을 직접 달았고, 한국어 찬양 가사는 주석에 적었습니다.
- 후렴 「あなたは良い方 いつも誠実な主 命ある限り 素晴らしい主を賛美する」가 네 번 돌아
  良い方(かた)·〜限り·〜なる·명사+する 이 몸에 붙습니다.
- 御手(みて)처럼 **높임의 御** 읽기가 나옵니다.

## 줄 시각

공식 일본어 자막 32큐를 그대로 썼습니다. 박 그리드는 `beats.py` 로 구했습니다(BPM 122.0).

## 읽어주기가 잘못 읽던 한자

| 본문 | 합성기가 읽던 소리 | 이 곡의 읽기 |
|---|---|---|
| 御手 | **お**て | **み**て |
| 良い方 | よい**ほう** | よい**かた** |
| 主を賛美する | **ぬし**を | **しゅ**を |

`tools/check_reading.py` 로 짚고 `tools/hear_tts.py` 로 실제 소리를 재어 가린 것만 `src/tts_fix.txt` 에 적었습니다.
같이 짚힌 得る(える)·私(わたし)는 제대로 읽고 있어 건드리지 않았습니다.

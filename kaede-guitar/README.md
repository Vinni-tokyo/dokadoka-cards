# スピッツ 「楓」 — 기타 블록 연습

YouTube 「スピッツ / 楓」(spitzclips 공식 MV, 2010-04 게시 · 원곡 1998-07-07, 5분 27초)의 **기타 코드 블록 연습 페이지**.
영상에 자막이 없어 **가사는 싣지 않습니다**(정식 발매곡 가사를 받아써 옮기지 않는다). 코드·마디만.

- 마디 블록 · 영상에 맞춰 지금 블록 강조 · 블록 누르기 재생/멈춤 · 🔁 이 칸 / 줄 반복 · 0.75×·0.5×
- 카포 모양 / 원래 코드 · 🎚 키 올리기·내리기(🔒 카포 고정 / 🔄 카포 자동) · 운지 그림
- 🎤 버스킹 모드(지금 4블록 코드 크게) · 🔂 한 곡 반복 · 🎵 전곡 듣기에 포함

코드: 음원 → demucs(반주 분리) → `tools/chord_simple.py` 자동 채보 — 조 A♭(G#)장조, 일치도 0.893, 81 BPM.
간이 코드라 경과 코드는 빠져 있고 일부 칸은 틀릴 수 있다.

```bash
python3 kaede-guitar/src/build.py      # tools/make_block_practice.py (numpy — 리포 .venv)
```

## 📝 내 가사 (자막 없는 곡의 가사 학습)

페이지 위 **📖 가사** 링크(歌ネット 등)에서 가사를 복사해 「📝 내 가사」 칸에 붙여 넣고 저장한다.
- 가사는 **그 기기 브라우저에만** 저장된다(사이트·리포에는 없다). 지우기·내보내기·가져오기(JSON) 가능.
- 저장하면 노래 구간(`src/phrases.json` — 목소리 트랙의 말소리 감지 시각만, `tools/vocal_phrases.py`)에 줄을 자동 배정한다.
  줄 수가 다르면 가장 짧은 틈부터 합치고 가장 긴 구간부터 나눈다. 어긋나면 **⏎ 탭으로 맞추기**(노래를 틀고 줄이 시작될 때마다 탭).
- 한자 위 읽기는 브라우저의 kuromoji.js(처음 한 번 사전 내려받음), 낱말을 누르면 네이버 일본어사전.
- 재생 막대·버스킹 화면에 지금 줄(버스킹은 가사 위 코드)이 나온다.

```bash
.venv/bin/python tools/vocal_phrases.py kaede-guitar vocals.wav   # demucs 의 vocals.wav (리포에 넣지 않음)
python3 kaede-guitar/src/build.py
```

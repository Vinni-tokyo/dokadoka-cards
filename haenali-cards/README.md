# 도카도카 일본어 공부 · ドカドカ日本語 — 해날이 왕기초 일본어 공부법

YouTube 「[왕기초 일본어 독학] 2달 안에 프리토킹 무조건 가능한 현실적 공부법」(Haenali 해날이 채널, 2024-02-17, 20분 13초)으로 만든
**일본어 학습 카드 앱**(한국어 모어 학습자용). 48장. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 32·단어 26.

영상은 **대부분 한국어 설명**입니다. 그중 **일본어로 말한 곳만** 카드로 만들었습니다.

| 장면(영상 설명란 타임라인) | 카드 | 내용 |
|---|---|---|
| 일본어 자기소개 (01:06) | 26 | 독학 1년 2개월·JLPT N2 합격까지의 이야기를 일본어로 |
| 일본어 발음 (06:21) | 6 | ざじずぜぞ · つ/ちゅ · 人間 · 大阪行きます · お父さん · ビール(장음) |
| 애니로 청해 공부하는 법 (10:07) | 9 | 영상 속 애니 「あたしンち」 장면 7줄 + 남녀 말투(ご飯食べたよ · 飯食った) |
| 실전회화 (13:20) | 5 | はじめまして · そうなんだ · あ、そうなんですか · なるほど(맞장구) |
| Q&A (15:21) | 1 | 気まずい |
| 마무리 (18:37) | 1 | ご覧いただきありがとうございます |

주석에는 그 대목에서 해날이 님이 한국어로 한 설명을 함께 적었습니다(예: つ 는 「추」와 비슷하게 들린다, 女는 ご飯食べたよ).

## 원문을 만든 방법 — 자막이 없다

- 수동 자막 트랙(`ja`)은 빈 줄 하나, 자동 자막도 비어 있습니다. 그래서 **음성 인식**으로 만들었습니다.
- faster-whisper `medium` 으로 말 구간(422개)마다 언어를 판별해 일본어 구간을 찾고, 일본어 구간만 `large-v3` 로 짧게 잘라 다시 받아써 대조했습니다.
  (`large-v3` 에 일본어를 강제하면 한국어 설명을 일본어로 「번역」해 버려서, 언어 판별을 먼저 했습니다.)
- 두 결과가 다른 곳은 문맥으로 정했습니다: この炎上→**この映像**, とかかく→**とにかく**, JRPT→**JLPT**.
- 본인이 실제로 그렇게 말한 학습자 표현(**ご覧してください · 自然的には · 一緒な目的**)은 고치지 않고 주석에 바른 형태를 적었습니다.
- 확정한 원문·시각·화자는 `src/lines.txt` 하나에 있습니다(이 파일이 정본). 단어 시각은 인식기의 단어 타임스탬프에서 잡았습니다.

## 읽어주기

`tools/check_reading.py` 가 13줄을 짚었는데 대부분 분석기의 오탐(私→わたくし, 日本→にっぽん)이었습니다. `tools/hear_tts.py` 로 실제 소리를 재어
**「日本の方と」를 にほんの「ほう」と 로 읽는 것** 하나만 확인돼 `src/tts_fix.txt` 로 고쳤습니다(始めた方·行きたい方 는 かた 로 바르게 읽음).

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8128). 카드·대본·학습(오늘/표현/단어/퀴즈/학습법)·드릴은 다른 일본어 앱과 같습니다.

## 구성

```
haenali-cards/
├─ Japanese-Haenali48-Cards.html   앱 (단일 파일, 데이터·음원 내장)
├─ start.bat / start.sh
├─ README.md
└─ src/
   ├─ lines.txt        원문 48줄 `시작|끝|화자|일본어` (음성 인식을 손으로 확정 — 정본)
   ├─ seg.py           lines.txt → segs.json
   ├─ build.py         최종 HTML 생성 (seg.py 를 먼저 실행)
   ├─ tpl.html         화면 템플릿 (japanese-cards 에서 복사)
   ├─ ko.txt           한국어 뜻·읽기·주석 48건  `id|뜻|읽기|주석`
   ├─ study.txt        표현 32 · 단어 26         `종류|일본어|읽기|뜻|메모`
   ├─ kanji.txt · words.txt · gen_words.py · lemma_*.py · check_cov.py   한자 풀이 사전
   ├─ tts_fix.txt      읽어주기 오독 보정
   └─ audio/           학습 음원 (tools/make_study_audio.py)
```

## 재빌드

```bash
cd src && ../../.venv/bin/python gen_words.py > words.txt && python3 build.py
../../.venv/bin/python ../../tools/make_study_audio.py haenali-cards --cards --gloss   # 음원(인터넷 필요) 후 build.py 재실행
```

받아쓰기를 다시 하려면 음원을 받아(리포에 넣지 않습니다) faster-whisper 로 돌립니다.

```bash
.venv/bin/yt-dlp -f bestaudio -x --audio-format wav --postprocessor-args "-ac 1 -ar 16000" -o "audio.%(ext)s" -- "qRzf-bi_FSI"
```

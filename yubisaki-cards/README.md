# 도카도카 일본어 공부 · ゆびさきと恋々 제1화

YouTube 영상 「【1話】ゆびさきと恋々 見逃し特別配信！【日本語字幕対応】」(フル☆アニメTV 공식, 2024-01-13, 25분)의
**방송용 일본어 CC 자막**으로 만든 **일본어 학습 카드 앱**(한국어 모어 학습자용).
대사 101장 + 속마음 84장 = 185장, 히라가나 읽기·한국어 뜻 병기.

청각장애가 있는 대학생 유키와 여행자 이츠오미의 첫 만남을 그린 1화입니다.
짧고 느린 일상 대화와 속마음 독백이 대부분이라, 같은 폴더의 다른 앱(인터뷰·예능)보다 **쉬운 일본어**입니다.
`japanese-cards/`(Snow Man 인터뷰)와 같은 구조이며, 이 폴더만 통째로 복사하면 다른 PC에서 그대로 실행·재빌드됩니다.

---

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8097). Python 3 가 필요합니다.
상위 폴더의 `start.bat`/`start.sh`(포트 8100)로 열면 관문 페이지에서 다른 영상 앱과 함께 고를 수 있습니다.

`Japanese-Yubisaki185-Cards.html` 을 그냥 더블클릭해도 카드·대본·학습·편집은 쓸 수 있지만,
**YouTube 가 `file://` 에서의 임베드 재생을 거부**하므로(Error 153) 재생 버튼은 YouTube 를 해당 대사 시각부터 새 탭으로 엽니다.
어느 방식이든 **인터넷 연결**이 필요합니다.

## 기능

- **카드** — 일본어 대사 + 히라가나 읽기(토글) + 한국어 뜻, 장면·화자별 필터, 체크 진도
- **한자 풀이** — 뜻 영역에 그 카드의 한자어마다 일본어 독음 · 한국 한자음 · 뜻 · 낱글자 훈음을 표시(예: 曇天 どんてん 「담천」 흐린 하늘 — 曇 흐릴 담 · 天 하늘 천). 사전은 `src/words.txt`·`src/kanji.txt`, 빌드가 자동 생성하고 누락 한자를 검사
- **표현 풀이** — 그 카드에 나오는 학습 표현(문형)의 뜻과 메모를 뜻 영역에 함께 표시
- **재생 구간 보정** — 「옆 카드 침범 금지」(기본 켜짐)로 붙어 있는 카드 사이에 앞뒤 대사가 새어 들어오지 않게 하고, 「시작 보정」(−0.3~+0.5초)과 카드별 「재생 구간 조정」(편집 박스: 시작/끝 ±0.3초, 「지금 위치로」)으로 자막 시각의 어긋남을 바로잡을 수 있음. 조정값은 브라우저에 저장되고 내보내기/가져오기에 포함
- **속마음** — 자막의 〈 〉(주인공 유키의 심중 독백)를 별도 칩으로 표시. 옵션으로 카드에서 뺄 수 있음
- **화자** — CC 자막의 （이름） 표기를 살려 등장인물 8명·엄마·외국인·안내방송 등으로 볼 수 있음
- **대본** — 185줄 목록(시각·화자·대사·읽기·뜻), 줄 클릭 시 그 위치부터 재생, 재생 중 자동 추종
- **재생** — 대사 시작점으로 점프, 구간 반복, 다음 카드 자동 재생, 재생 여유(기본 0.5초)
- **드릴** — 학습 탭의 기본 화면. 유튜브 없이 단어·표현만 외우는 암기 드릴. 브라우저 내장 음성(TTS)으로 읽어 주고, 카드를 보고 떠올린 뒤 「몰라/애매/알아」로 채점하면 틀린 것은 같은 세션에서 곧 다시 나오고, 세션이 끝나면 0·1·3·7·14일 간격으로 다시 물어봄(브라우저에 저장). 방식은 日→韓 / 韓→日 / 듣기, 「자동 반복 듣기」는 손을 놓고 원문→뜻→원문 순으로 계속 읽어 줌. 「영상」 버튼으로만 원음을 들음
- **오늘** — 185장을 페이스(천천히 18 / 보통 26 / 빠르게 37 / 집중 62장)로 나눈 일일 분량. 보통 기준 8일 완성
- **학습** — 표현 49 · 단어 51. 각 항목이 나오는 자막 위치를 자동으로 찾아 예문·클립 재생 연결
- **퀴즈** — 표현/단어/대사/오늘 분량 × 日→韓 / 韓→日 / 듣기, 4지선다
- **학습법** — 4단계 가이드와 팁 6가지
- **직접 편집** — 대사·읽기·뜻을 고쳐 저장(브라우저 저장). `내보내기`/`가져오기` 로 백업·이전

> 학습 기록(직접 수정한 내용)은 파일이 아니라 **브라우저**에 저장됩니다.

## 구성

```
yubisaki-cards/
├─ Japanese-Yubisaki185-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh               실행기
├─ README.md
└─ src/
   ├─ subtitles.srt                   원본 자막 (YouTube 공식 일본어 CC, yt-dlp 로 받음)
   ├─ seg.py                          자막 → 카드 분할 (화자·속마음·효과음·가사 구분)
   ├─ build.py                        최종 HTML 생성 (seg.py 를 먼저 실행)
   ├─ tpl.html                        화면 템플릿 (HTML/CSS/JS)
   ├─ ko.txt                          한국어 번역·읽기 185건  `id|뜻|읽기|주석`
   ├─ words.txt                       한자어 사전 159건        `어간|표제|독음|뜻|한자음`
   ├─ kanji.txt                       한자 훈음 사전 174자     `漢字|훈 음`
   └─ study.txt                       학습 표현·단어 100건     `종류|일본어|읽기|뜻|메모`
```

## 재빌드

```bash
python3 src/build.py
```

### 이 자막 형식의 특징 (seg.py)

방송용 CC 자막은 다음 규칙으로 되어 있어 분할기가 그에 맞춰져 있습니다.

- `（雪）대사` — 화자 태그. **화자가 바뀔 때만** 붙으므로, 태그 없는 발화는 직전에 태그가 붙은 발화자로 추정합니다(`inf`).
  추정이 틀린 곳은 `seg.py` 의 `SPK_FIX` 에 큐 번호로 지정해 두었습니다(15곳).
- `〈…〉` — 속마음(주인공 유키). 태그가 없으면 유키의 것으로 봅니다.
- `（심장의 고동）` `（문 여는 소리）` 등 효과음, `♪` 가사(OP·ED 36줄)는 카드에서 제외합니다.
- 본문의 후리가나 `橋元(はしもと)` 는 떼고, 읽기 줄(`ko.txt`)에 넣습니다.

# 도카도카 일본어 공부 · ドカドカ日本語 — 秦基博「ひまわりの約束」

YouTube 「秦 基博 - 「ひまわりの約束」 Music Video」(HATA MOTOHIRO 공식 채널, 5분 17초)로 만든
**일본어 노래 학습 카드 앱**(한국어 학습자용). 36줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 21·단어 12.
영화 『STAND BY ME ドラえもん』 주제가.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- **공식 채널에 공식 일본어·한국어 자막이 둘 다 붙어 있습니다.** 작업 문서의 최상 등급(A)입니다. 음성 인식을 쓰지 않았습니다.
- 「そばにいたいよ」로 여는 후렴이 세 번 돌고, 5번 줄 「〜だったはずの」가 19번 줄에서 되돌아옵니다.
  7번 「そばにいたい」가 21번에서 「そばにいること」로, 14번 「気づいた」가 마지막 줄에서 「見つけた」로 바뀝니다.
- 〜のに·〜なくなる·〜ていてほしい·〜ても·가능형+〜と信じて·〜のことだから 같은 문형이 고루 나옵니다.

## 줄 시각

공식 자막 두 벌에서 만들었습니다. 일본어 자막은 29큐에 36줄이 들어 있고(한 큐에 두 줄인 것 7개),
한국어 자막은 36큐로 줄마다 시각을 갖고 있습니다. **두 줄이 든 큐는 그 시간에 겹치는 한국어 큐 두 개의 시각을
줄마다 그대로 썼습니다**(`tools/mk_song.py` 가 그렇게 합니다). 나머지는 일본어 큐의 시각 그대로입니다.
박 그리드(`src/beats.json`)는 `beats.py` 로 구했습니다(BPM 158.7).

## 읽어주기

`tools/check_reading.py` 가 宝物·言う 두 곳을 짚었는데 `tools/hear_tts.py` 로 재어 보니
たからもの·いう 로 제대로 읽고 있어 보정하지 않았습니다.

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8124). 학습 탭·노래방·화면 잠금은 다른 노래 앱과 같습니다.

## 재빌드

```bash
cd src && ../../.venv/bin/python gen_words.py > words.txt && python3 build.py
../../.venv/bin/python ../../tools/make_study_audio.py himawari-cards --cards --gloss   # 음원(인터넷 필요) 후 build.py 재실행
```

줄 시각을 다시 만들려면 공식 자막을 받습니다(리포에 넣지 않습니다).

```bash
.venv/bin/yt-dlp --skip-download --write-subs --sub-langs "ja.*,ko.*" --sub-format srt \
  --convert-subs srt -o "%(id)s.%(ext)s" "https://youtu.be/rKsQ-3N-Bks"
```

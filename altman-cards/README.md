# 도카도카 영어 공부 · Sam Altman on Bloomberg TV

YouTube 영상 「OpenAI's Sam Altman on Astra Model Debut, Benefits of AI」(Bloomberg Television 공식, 2026-09-03, 12분 33초)의
**Bloomberg 공식 영어 캡션**으로 만든 **고급 영어 학습 카드 앱**(한국어 모어 학습자용).
대사 123장, 한국어 뜻·주석 병기(주석 120장), 자막 오기 교정 16장.

Bloomberg 앵커가 OpenAI CEO 샘 올트먼에게 신모델 Astra 의 차별점 · 가드레일과 사이버 접근 등급 · 출시 전 일시중단 · 사고 사슬(chain of thought) 모니터링 · 위험 감지와 사회적 합의 · 업계의 설명 실패 · 가격과 토큰 효율 · 상장과 사명을 차례로 묻는 1:1 인터뷰입니다.
문장이 길고 정보 밀도가 높으며(카드 평균 100자), `it's worth pointing out that…` `we want to be clear…` `on reflection…` 같은 담화 표지가 풍부한 **비즈니스·정책 영어**입니다. 같은 폴더의 젠데이아 인터뷰(`english-cards/`)보다 한 단계 위 난이도입니다.

## 실행

| 환경 | 방법 |
|---|---|
| Windows | `start.bat` **더블클릭** |
| Linux / mac | `./start.sh` |

간이 서버를 띄우고 브라우저를 엽니다(포트 8095). Python 3 가 필요합니다.
`English-Altman123-Cards.html` 을 그냥 더블클릭하면 카드·대본·학습·편집은 쓸 수 있지만 YouTube 가 `file://` 임베드를 거부하므로(Error 153) 재생 버튼은 YouTube 를 해당 시각부터 새 탭으로 엽니다. 어느 방식이든 인터넷 연결이 필요합니다.

## 기능

- **카드** — 영어 대사 + 한국어 뜻(가리기/보기) + 주석, 장면·화자별 필터, 체크 진도
- **화자** — 올트먼 89장 · 진행자 34장. 캡션에 화자 표시가 없어 `src/turns.txt` 에 18곳의 전환 지점을 직접 지정
- **장면** — 질문 주제별 8장면(Astra → 가드레일 → 일시중단 → 사고 사슬 → 위험 감지 → 메시지 → 가격 → 상장)
- **대본** — 123줄 목록, 줄 클릭 시 그 위치부터 재생, 재생 중 자동 추종
- **재생** — 대사 시작점으로 점프, 구간 반복, 다음 카드 자동 재생, 재생 여유
- **오늘** — 123장을 페이스(천천히 9 / 보통 13 / 빠르게 18 / 집중 25장)로 나눈 일일 분량. 보통 기준 10일 완성
- **학습** — 표현 66 · 단어 53. 각 항목이 나오는 자막 위치를 자동으로 찾아 예문·클립 연결
- **퀴즈** — 표현/단어/대사/오늘 분량 × EN→KO / KO→EN / 듣기, 4지선다
- **학습법** — 4단계 가이드와 팁 6가지(앵커의 맥락 깔기 질문과 올트먼의 틀 잡기 답변 등 이 영상에 맞춰 씀)
- **직접 편집** — 대사·뜻을 고쳐 저장(브라우저 저장). 내보내기/가져오기로 백업

## 구성

```
altman-cards/
├─ English-Altman123-Cards.html   앱 (단일 파일, 데이터 내장)
├─ start.bat / start.sh           실행기
├─ README.md
└─ src/
   ├─ subtitles.srt               원본 자막 (Bloomberg 공식 영어 캡션 `en`, yt-dlp 로 받음)
   ├─ turns.txt                   화자 전환 지점 18곳  `구절|화자`
   ├─ fixes.txt                   자막 오기 교정 16장   `id|교정문` (원문은 raw 로 보존)
   ├─ seg.py                      자막 → 카드 분할 (문장 끝 + 화자 전환 구절에서 자름)
   ├─ build.py                    최종 HTML 생성 (seg.py 를 먼저 실행, 파일명의 숫자 = 카드 수)
   ├─ tpl.html                    화면 템플릿
   ├─ ko.txt                      한국어 번역·주석 123건  `id|뜻|주석`
   └─ study.txt                   학습 표현·단어 119건    `종류|영어|뜻|메모`
```

## 재빌드

```bash
python3 src/build.py
```

### 이 자막 형식의 특징 (seg.py)

- 큐가 문장 중간에서 끊기고 **화자 표시가 없습니다**. 큐를 전부 이어 붙여 문장 끝(`.?!` + 대문자)과 `turns.txt` 의 화자 전환 구절에서 자르고, 글자 위치 ↔ 큐 시각 대응표로 재생 시각을 보간합니다.
- 200자를 넘는 한 문장은 `, and / , but / , because / , so` 절 경계에서 한 번 더 나눕니다.
- 공식 캡션이지만 `AI`→`I`/`eye`, `Astra`→`Aster`, `Bessent`→`Besson`, `monitorability`→`vulnerability` 같은 오기가 있어 뜻이 바뀌는 16장만 `fixes.txt` 로 고쳤습니다. 원문은 데이터의 `raw` 에 남습니다.
- 캡션에 `Um, uh` 같은 필러가 그대로 있습니다. 번역에서는 뺐고, 학습법 탭에서 흘려 듣는 연습으로 다룹니다.

# 도카도카 일본어 공부 · ドカドカ日本語 — 川崎鷹也「魔法の絨毯」

YouTube 「川崎鷹也-魔法の絨毯【OFFICIAL MUSIC VIDEO】」(川崎鷹也【公式】, 2020-09, 3분 19초)로 만든
**일본어 노래 학습 카드 앱**(한국어 학습자용). 30줄. 한국어 뜻·히라가나 읽기·주석·한자 풀이·표현 22·단어 16.

## 이 곡을 고른 이유

- 앱 안 재생을 착수 전에 확인했습니다(`tools/embed_check.py` → OK).
- **공식 채널에 공식 일본어·한국어 자막이 둘 다 붙어 있습니다.** 작업 문서의 최상 등급(A)입니다.
  가사와 줄 시각이 모두 권리자가 직접 공개한 자막에서 나오고, 한국어 뜻도 공식 번역을 기준으로 다듬었습니다.
- 1억 1,400만 회 재생. 이 가수를 알린 곡입니다.
- 후렴이 세 번 돌면서 같은 자리의 말만 바뀝니다(「迎えに行くよ」↔「笑わせるよ」,
  「離したくない」↔「守りたい」, 마지막 후렴은 けど 를 빼고 「なにもない」로 맺습니다).
  짝을 이루는 줄은 주석에 표시했습니다.
- 「〜合う」가 세 줄 잇달아 나오고, 「〜ないように」「仮に〜ても」「〜のように」가 반복됩니다.

## 줄 시각

공식 자막 두 벌에서 만들었습니다. **음성 인식을 쓰지 않았습니다.**
일본어 자막은 16큐에 30줄이 들어 있고(한 큐에 여러 줄), 한국어 자막은 30큐로 줄마다 시각을 갖고 있습니다.
줄 수가 맞는 큐에서는 **한국어 자막의 시각을 그대로 썼고(18줄)**, 나눔이 어긋난 큐에서만
일본어 큐 안을 글자 수 비율로 나눴습니다(12줄). 한국어 뜻은 시간이 겹치는 정도로 짝지었습니다
(순서대로 짝지으면 최대 16초까지 어긋납니다 — 두 자막이 나누는 지점이 다릅니다).
박 그리드(`src/beats.json`)는 `beats.py` 로 구했습니다(BPM 144.1 · 4/4 · 120마디).

## 학습 탭

**오늘 · 복습 · 목록 · 학습법** 넷. 「오늘」은 단락(1절 · 프리코러스 · 후렴 · 마지막 후렴) 단위로
들으며 읽기 → 마디 따라 부르기 → 가사 가리고 부르기 → 표현·단어 4단계를 안내합니다.
가사 30줄·표현·단어·한자 풀이 표제어는 **일본어 음원(edge-tts)** 139개를 내장해
「읽어주기」가 오프라인에서도 됩니다. 음원은 −22 LUFS 로 정규화돼 있고 🔈 버튼으로 음량을 바꿉니다.

## 노래방·화면 잠금

가사 중심 화면입니다. 늘 고정되는 것은 아래 이동 바 한 줄뿐이고, 마디·미세 조정은
오른쪽 끝 버튼으로 여는 서랍에 있습니다. 탭 줄 오른쪽 끝 자물쇠를 누르면 화면이 잠기고
**2초간 꾹 누르면** 풀립니다(PC 는 Esc). 잠긴 동안에도 영상과 읽어주기는 계속 재생됩니다.

## 구성

```
mahou-cards/
├─ Japanese-Mahou30-Cards.html   앱 (단일 파일, 데이터·음원 내장)
├─ start.bat / start.sh
├─ README.md
└─ src/
   ├─ lyrics.txt        가사 30줄 (빈 줄 = 구간 경계) — 공식 일본어 자막에서
   ├─ subtitles.srt     줄별 시각 (공식 한국어 자막 시각 18줄 + 비율 분할 12줄)
   ├─ _ko_official.txt  공식 한국어 자막을 줄에 짝지은 것 (뜻을 다듬을 때의 기준)
   ├─ ko.txt            id|한국어 뜻|읽기|주석 — 학습용으로 직접 작성
   ├─ kanji.txt         한자 훈음 48자 (가사 한자 46자 100% 커버, 빌드가 검사)
   ├─ words.txt         한자어 사전 40항목 (gen_words.py 로 생성)
   ├─ gen_words.py / lemma_meanings.py / lemma_base.py / check_cov.py
   ├─ study.txt         표현 22 · 단어 16
   ├─ segs.json         가사 줄 목록 (gen_words·check_cov 용)
   ├─ beats.json / beats.py / align.py
   ├─ audio/            edge-tts 음원 139개 + index.json
   ├─ build.py          최종 HTML 생성
   └─ tpl.html          화면 템플릿 (kandagawa-cards 와 동일 계열)
```

## 재빌드

```bash
cd src && ../../.venv/bin/python gen_words.py > words.txt && python3 build.py
../../.venv/bin/python ../../tools/make_study_audio.py mahou-cards --cards --gloss   # 음원(인터넷 필요) 후 build.py 재실행
```

줄 시각을 다시 만들려면 공식 자막을 받습니다(리포에 넣지 않습니다).

```bash
.venv/bin/yt-dlp --skip-download --write-subs --sub-langs "ja,ko" --sub-format srt \
  --convert-subs srt -o "%(id)s.%(ext)s" "https://youtu.be/R7wI90H6Wuc"
# 일본어 큐를 줄바꿈으로 펼치고, 한국어 큐와 줄 수가 맞는 곳은 그 시각을 그대로 쓴다
python3 ../tools/fix_cue_ends.py src/subtitles.srt   # 잘린 끝 시각 보정
.venv/bin/python src/beats.py mh.wav                 # → beats.json
```

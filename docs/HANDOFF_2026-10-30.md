## A. courage-guitar 가사 얹기 — **완료**

Lofi Brew 「Courage Within」(영상 `9cbcKa3gE9Y`) 기타 페이지에 **가사 위에 코드**를 얹었다.

| 산출물 | |
|---|---|
| `courage-guitar/chords.html` | **신규** — 다른 노래 앱 26곡과 같은 간이 코드 악보 판형 |
| `courage-guitar/index.html` | 블록 연습은 코드만 유지 + 「‹ 코드 악보(가사)로」 링크 |
| `courage-guitar/src/lyrics.txt` · `subtitles.srt` | 가사 24줄 · 줄별 시각 |

**줄 시각을 만든 경로** — 이 영상엔 수동·자동 자막이 **전혀 없다**.

```bash
.venv/bin/yt-dlp -x --audio-format wav -o song.wav <URL>
.venv/bin/python -m demucs --two-stems vocals -o sep song.wav
.venv/bin/python tools/asr_words.py sep/htdemucs/song/vocals.wav out --model large-v3 --lang en
python3 tools/align_dp.py courage-guitar/src/lyrics.txt out/words.json courage-guitar/src/subtitles.srt
```

결과 **24줄 전부 매칭 · 보간 0 · 유사도 평균 0.98**. 재빌드는 `python3 courage-guitar/src/build.py` 한 번으로 두 페이지가 같이 나온다.

**남은 것** · PR 생성뿐. 곡 끝 애드리브(약 3분 20초, 6초)는 가사에 넣지 않았다.

## 알아 둘 함정 (전부 실물에서 걸린 것)

**① `asr_words.py` 는 일본어 고정이었다**
`language='ja'` 가 박혀 있어 **large-v3 가 영어 곡을 일본어로 환각**했다(「おやすみなさい」만 8줄). `--lang` 옵션을 더했고 **기본값은 `ja` 그대로**다. 영어 곡은 반드시 `--lang en`.
medium 모델은 앞 60초를 통째로 놓쳤다 — **영어 곡은 large-v3 + `--lang en`** 이 기준.

**② 코드 악보의 구간 라벨이 한 줄씩 밀린다 — 다른 앱 6개에 아직 남아 있다**
`make_chord_sheet.py` 가 `lyrics.txt` 의 `#` 주석을 가사 줄로 세고 있었다. 「1절」에 5줄이 들어가고 후렴이 둘째 줄에서 시작한다.
**도구는 고쳤지만**(`feat/courage-lyrics` 브랜치에만 있다 · `origin/main` 에는 아직 없다) 아래 6개 앱의 `chords.html` 은 **옛날 것 그대로**다.

```
betelgeuse-cards  firstlove-cards  hanabi-cards  reasons-cards  saranghagi-cards  yukinohana-cards
```

재생성은 요청 밖이라 하지 않았다. 하려면 각 앱에 `make_chord_sheet.py` 를 다시 돌린다.

**③ `linesFrom` 은 노래 앱만 읽을 수 있다**
블록 연습 페이지에 `--back` 으로 코드 악보를 걸었더니 `linesFrom` 이 **코드 악보를 노래 앱으로 오해**했다. `*-Cards.html` 일 때만 읽도록 좁혔다.

**④ Goal V1 의 등급 수치는 한 번 바뀌었다 (202 → 197)**
착수 전 실사 D3 을 잰 스크립트에 **적히지 않은 규칙**이 있었다 — 두 낱말짜리 단어 6개(`role model` `control freak` 등)를 구성 단어의 최난도로 채점하고 있었다. 관용구에서 금지한 것과 같은 기제라 **사용자 결정 (a)** 로 그 6개는 등급 없이 「목록 밖」으로 보냈다. 사양서·DESIGN 의 수치는 197/90 으로 고쳐 두었다.

**⑤ 영상은 고르기 전에 `tools/embed_check.py`** — 저작권자가 앱 밖 재생만 막아 둔 영상이 있고 yt-dlp 메타데이터로는 안 잡힌다.

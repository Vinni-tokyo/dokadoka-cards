02

지금 화면에서 보이는 것 (모바일 390px)

    공통 · PC와 모바일
  • 1단계 이름이 세 군데에서 다르다. 하위 탭(드릴·오늘·표현·단어·퀴즈·학습법), 오늘 탭 띠(듣기›표현·단어›퀴즈›복습), 학습법 탭(듣기›확인›따라 하기›점검).
  • 2오늘 탭의 4단계 띠가 장식이다. 누를 수 없고 완료 표시가 없다. 「완료」는 Day 전체 수동 체크.
  • 3드릴 설정이 매번 12개 컨트롤. 범위·방식·크기·음성·속도·자동 읽기·반복·뜻과 함께. 시작 버튼이 맨 아래.
  • 4채점 버튼이 카드 아래. 모바일에서는 화면 밖. 터치 기기에서는 키보드 힌트도 숨겨져 대안이 없다.
  • 5「듣기」 단계가 학습 탭 밖에 있다. 「카드로」를 누르면 카드 뷰로 나가고 돌아오는 길이 없다.
  • 6드릴 결과가 다음 날 행동으로 이어지지 않는다. SRS 기한은 저장되지만 「오늘 복습 N」 숫자뿐.
    • 모바일
  • 7플레이어가 학습 뷰에서도 210px. 드릴·퀴즈는 영상을 쓰지 않는데 콘텐츠가 화면 절반 아래에서 시작.
  • 8하위 탭 6개가 두 줄. 폭이 들쭉날쭉하고 어느 줄이 현재인지 읽기 어렵다.
  • 9Day 띠 25개가 한 줄에. 「1011121314…」로 겹쳐 보인다.
    • 노래 앱
  • 10학습 탭·학습법이 토크쇼용 복사본. 「반복 C」·「퀴즈」·「카드」 용어 그대로. 노래에 필요한 단계가 없다.
  • 11마디 반복 13개 컨트롤이 한 상자. 모바일 4줄. 노래방 탭에는 없어서 두 탭을 오가야 한다.
  • 12외우기 단계가 없다. 노래방의 가리기 옵션은 읽기·뜻 체크박스뿐.
03

설계 원칙

단계 하나, 화면 하나

세션은 「오늘」 홈에서 시작해 홈으로 돌아온다. 단계 이름은 학습법의 넷(듣기 · 확인 · 따라 하기 · 점검)으로 통일.

설정은 접는다

기본값으로 바로 시작. 음성 · 속도 · 반복 횟수는 앱 전역 설정에서 한 번만.

판정은 엄지 영역

모바일의 채점 · 다음 버튼은 하단 고정 바. 카드 본문은 위쪽.

진행이 보인다

단계별 완료 체크, 연속 학습일, 복습 대기 수를 홈에서 바로.

영상은 필요할 때만

학습 탭의 모바일 플레이어는 미니 바로 접고, 듣기 · 따라 하기 단계에서만 펼친다.

시안 A · 일본어 학습 앱 (mika 계열)

A1 · 「오늘」 홈 = 4단계 스테퍼

하위 탭 6 → 4 (오늘 · 복습 · 목록 · 학습법)

드릴 · 퀴즈 · 표현 · 단어는 탭이 아니라 단계 안에서 열립니다. 각 단계 카드에 분량 · 예상 시간 · 상태 · 버튼 하나. 끝난 단계는 초록, 지금 단계는 남색 테두리.

  • Day 띠 → 「‹ DAY 3 ›」 + 진행 바 (PC 는 가로 스크롤, 현재 중앙)
  • 복습 탭에 SRS 기한 · 퀴즈 오답 · 체크 카드를 한 목록으로, 버튼 하나
  • 모바일 플레이어는 미니 바 (제목 · 재생 · 시각)
  • 4단계를 모두 마치면 Day 완료가 자동 체크

시안 B · 일본어 노래 앱 (First Love 계열)

B1 · 노래 4단계 홈

단계대상바꾸는 것확인 방법

TIER 1학습 효과에 직결

모두 브라우저만으로 됩니다. 서버 · 외부 API 없음.

  1. FSRS 스케줄러 — 안정도 · 난이도 · 기억 확률. 기존 lv/due 는 1회 이관. JS 200줄
  2. 루비 후리가나 + 피치 액센트 — fugashi 가 이미 aType 을 냅니다 (本当⓪ おっしゃる③ テレビ①). 빌드 타임 생성.
  3. 단어 탭 → 사전 팝오버 + 단어 상태 3색 — 문장별 「모르는 단어 수」가 생겨 오늘 분량을 i+1 순으로 정렬.
  4. 받아쓰기 · 빈칸 퀴즈 — 듣고 타이핑, 조사 빈칸, 노래는 가사 빈칸. 부분 점수.
  5. 섀도잉 녹음 · 비교 — 내 목소리 ↔ 원음 A/B, 파형 겹침. 로컬 저장.
  6. 토크쇼 재생 속도 — 0.75 · 0.85 · 1×, 「몰라」 뒤 자동 감속.
  7. 3분 마이크로 세션 + 종료 보고

TIER 2속도 · 휴대 · 접근성

매일 여는 앱의 마찰을 없앱니다.

  1. PWA + Service Worker — 즉시 기동 · 오프라인(YouTube 만 온라인) · 홈 화면 설치.
  2. Media Session + Wake Lock + 오디오 전용 — 잠금화면 · 이어폰 버튼, 「걸으며 듣기」.
  3. 다크 모드 + 접근성 — aria-live 채점, 44px 타겟, 단축키 한 벌(J/K · Space · 1·2·3 · R · C).
  4. 30초 온보딩 — 「오늘 5분 시작」 버튼 하나.
  5. 허브 대시보드 — 같은 오리진이라 허브가 각 앱 진행을 읽음. 전체 백업 JSON.
  6. Anki 내보내기 — 체크한 문장 + 음원.

TIER 3측정으로 만드는 품질

세계 최고는 감이 아니라 숫자로 다듬습니다.

  1. 로컬 사용 로그 → 학습 리포트 — 세션 완료율, 카드당 탭 수, 첫 재생까지 시간. 외부 전송 없음.
  2. 빌드 시 UX 회귀 검사 — 390 · 1400 스크린샷 + 규칙(첫 재생까지 탭 ≤ 2, 채점 버튼 뷰포트 안, 가로 스크롤 0).
  3. 데이터 품질 게이트 전 앱 적용 — 시작 보정 · 한자 커버 · 읽기 오류 목록을 빌드에 강제.

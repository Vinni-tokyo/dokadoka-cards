## 2. 사용자가 내린 결정 (바꾸려면 사용자에게 물을 것)

- **상업 언론사(WSJ·FT 등) 자막 전문은 담지 않는다.** 처음 고른 4편을 버리고 TED 로 교체했다. 개인 학습용이어도 공개 리포라는 이유.
- **음원 mp3 파일은 만들지 않는다**(용량). 생성 스크립트·파일 전부 삭제됨.
- **화면을 끈 채 듣기는 포기.** 잠금 화면 미디어 컨트롤·저음 킵얼라이브·주머니 모드(검은 덮개)는 전부 제거했다. 듣기 모드는 화면을 켠 채 쓰는 기능.
- 급수는 **JLPT N5~N1 + 급수 외**(사이트 빈도 급수는 폐기). 장 크기 기본 15장(10~50 선택).
- 홈 헤더: 왼쪽 「⌂ 메인」(관문으로), 오른쪽 「ⓘ 안내」. 듣기 모드 버튼은 홈 맨 위.
- 예문은 카드가 뜰 때부터 화면에 보인다(읽는 순간 테두리 강조).

## 3. 기술적으로 확정된 사실 (다시 시도하지 말 것)

- **Google 번역 음성(`translate_tts?client=tw-ob`)은 Referer 가 붙으면 404 HTML 을 돌려준다** → `onerror 4`. 페이지에 `<meta name="referrer" content="no-referrer">` 가 있어야 한다(있음). 서버 curl 검사와 실제 크롬 검사로 확인했다.
- 크롬(안드로이드)은 **5초 미만의 소리를 효과음으로 취급**해 화면이 꺼진 뒤 새로 시작하지 못한다. 학습 클립(1~3초)은 전부 해당. 긴 트랙 하나(≥5초)만 미디어 세션을 받는다. 클립을 이어 붙이려면 음성 바이트가 필요한데 Google 은 CORS 를 막는다 → 정적 페이지로는 불가. 가능한 길은 Cloudflare Worker 같은 중계 서버뿐(사용자가 보류).
- 기기 음성(speechSynthesis)은 백그라운드에서 멈추고, 돌아와도 「말하는 중」인 채 굳는다 → 화면 복귀 시 `cancel()` 후 재개(구현됨). 기기 신경망 음성은 CPU 를 써서 오래 들으면 폰이 뜨거워진다.
- 외부 사전: Unihan(Unicode License)·KanjiVG(CC BY-SA 3.0)·kanji-data(MIT, JLPT). 원본은 `~/.cache/dokadoka-kanji/`, 리포에는 추린 `src/dict.json` 만. **앱은 KanjiVG 파생물이라 CC BY-SA 3.0 표기 유지.**
- 사내 훈음 오류 8자(摺·体·画·台·予·円·吊·担)는 `src/hun.txt` 로 교정. 신자체→정자체 115자 `src/kyujitai.txt`. 한국음 없는 한자는 込·働·丼 3자뿐.
- 소리 가족은 구성 트리 × 주 음독 2개, 흔한 부품은 비율(≥0.4)로 거름, 청탁음 짝(ホウ/ボウ)은 병합 → 166가족(9/13 기준).
- 듣기 재생 화면의 **「진단」** 버튼이 클립별 재생 기록(`tts` 접두어 = 기기 음성, `onerror`, `play 거부`)을 보여 준다. 소리 문제는 이것부터 본다. 홈 하단에 빌드 시각이 있어 캐시 여부를 눈으로 확인할 수 있다.

## 4. 남은 일 (미배정)

1. 기억 보강 4개 — 간격 반복(날짜 넘어 복습 큐) · 뜻→漢字 4지선다(혼동 한자 오답) · 한국음↔음독 대응 규칙(ㄱ→ク/キ, ㄹ→ツ/チ, ㅁㄴ→ン) · 부품 색칠(KanjiVG 그룹별 색)
2. 한국어 한자어 예 `src/hanja_ko.txt` 3~5급 759자(현재 1·2급 204자만)
3. 다른 앱들에도 「메인」 링크
4. 화면 끈 채 듣기가 다시 필요해지면: Cloudflare Worker 로 카드 1장 음성을 한 파일로 합쳐 내려 주는 중계(≥5초 → 미디어 세션 자격)
5. SnowMan(japanese-cards)은 한자 사전이 없어 한자 카드에서 빠져 있음(사전 쓰면 자동 편입)

# 듣고 탭 — 일본어 단어 게임

사이트의 일본어 앱(노래·애니·인터뷰 28편)에 나온 단어 **1,816개**를 모아 「소리를 듣고 뜻을 탭」하는 게임.
`index.html` 하나와 단어 음원 `audio/` 로 돌아간다.

## 규칙

- **한 판 1분.** 소리가 나오고 단어가 보이면 뜻 4개 중 하나를 탭한다.
- 맞히면 「딩」·콤보. 콤보 5마다 점수 배수가 오른다.
- **탭하면 한자의 훈음(뜻과 음)이 보인다**(예: 行 다닐 행). 먼저 보이면 답이 새어 나와서 탭한 뒤에만 보인다.
  맞히면 1초 머물러 훈음을 볼 시간을 주고, 그동안은 시계를 멈춘다. 훈음은 앱들의 kanji.txt 중 가장 많이 쓴 것,
  kanji-cards/src/hun.txt(표준 훈음 교정)를 우선 — 게임 단어의 한자 1,089자 전부 있다.
- 틀리면 정답과 그 단어가 나온 **노래·영상의 한 줄**을 보여 주고 다시 들려준다. 「🎵 노래·영상에서 듣기」로 그 구간을 원래 소리로 듣는다(818단어).
- **같은 단어를 세 번 연달아 맞히면 「익힘」.** 1·3·7·21일 뒤에 다시 확인하고, 틀리면 한 단계 내려간다.
- 틀린 단어는 2문제 뒤, 맞힌(아직 익히지 않은) 단어는 3~5문제 뒤에 다시 나온다.
- 한 판의 문제: 복습할 때가 된 단어 → 익히는 중인 단어 → 새 단어(여러 곡에 나온 것부터).
- 기록은 폰 안(localStorage)에만 남는다. 로그인 없음.

## 스테이지

**곡(앱) 하나 = 스테이지 하나.** 첫 화면에 29개가 「노래 11 · 찬양 11 · 애니·영상 7」로 묶여 나온다.
- 스테이지를 고르면 그 곡의 단어만 나온다. 새 단어는 가사에 나온 차례대로 끼워 넣는다.
- 칸마다 「익힘 x / y」 막대와 별: 1/3 ★ · 2/3 ★★ · 전부 ★★★(클리어). 처음 다 익힌 판 끝에 「🎉 스테이지 클리어!」.
- 틀렸을 때 예문은 **지금 스테이지 곡의 줄**(곡별 예문 1,303쌍). 그 곡에 없으면 처음 찾은 줄.
- 「▶ 이어서」는 마지막으로 고른 스테이지. 「🔀 전체 곡에서 섞기」는 여러 곡에 나온 단어부터.
- 다 익힌 스테이지도 다시 고르면 연습으로 그 곡 단어를 섞어 낸다.

## 단어장 (📖)

스테이지 칸 오른쪽 📖 — 그 곡의 단어를 가사에 나온 차례대로 한 화면에 훑어본다(게임 없이).
- 단어마다 읽기 · 뜻 · 한자 훈음 · 그 곡에서 나온 줄 · 🔊.
- 「▶ 전부 듣기」: 차례로 읽어 주며 지금 단어를 따라 표시한다(오디오 요소 하나를 돌려 써 폰에서도 이어 재생).
- 「✓ 알아요」: 바로 「익힘」(1단계)으로 올려 게임에서 뺀다. 다음 날 한 번 확인 문제로 나오고 틀리면 다시 게임으로. 다시 누르면 되돌린다.
- 「게임으로 ›」: 같은 스테이지로 바로 게임.

## 만드는 법

```bash
cd wordtap/src && ../../.venv/bin/python build.py            # 단어 수집 + 음원(새 단어만) + index.html
../../.venv/bin/python build.py --no-audio                    # 데이터·페이지만
```

- 단어: `*-cards/src/words.txt`(일본어 앱이 만든 한자어 사전). 새 앱을 올린 뒤 build.py 를 다시 돌리면 단어가 늘어난다.
- 순서: 여러 앱에 나온 단어일수록 앞(세 곡 이상 276개).
- 예문: 그 단어가 「따로 선 단어」로 나오는 첫 줄(한자 한 글자 단어가 더 긴 한자어 속에서 걸리지 않게 거른다).
- 음원: **화면에 보이는 히라가나 읽기**를 edge-tts(ja-JP-NanamiNeural, -10%)로 읽힌다. 한자를 읽히면 主→ぬし 처럼 틀린다.
  같은 읽기는 파일 하나를 함께 쓴다(1,816단어 → 1,721파일, 14MB). −22 LUFS 로 정규화.
- 뜻이 「불명」이거나 읽기가 없는 항목은 뺀다.
